# Wotagei-Compare

Wotagei-Compare 是一款面向 WOTA 艺（御宅艺）练习者的移动端同台视频对比与慢放扒技工具（Android 优先原生跨平台 App）。旨在解决练习现场无法立即将自己的练习视频与高手参考视频进行空间对齐、卡拍对齐和超慢放对比的痛点，大幅缩短动作迭代反馈周期。

## 核心特性

* **强制横屏工作流**：遵循「视频1图像对齐 → 视频2图像对齐 → 视频1音频对齐 → 视频2音频对齐 → 同台对比播放与导出」的线性全屏标定向导，兼顾手机端标定精度与同台对比视野。
* **双模式空间对齐**：
  * **左右分区模式**：单次手绘人物裁剪框，自动等比居中放大填满各自半屏。
  * **半透明叠加模式**：采用**三线正交锚定法**（可选「两横一竖」对齐上半身头裆与中轴，或「两竖一横」对齐双脚与地面），支持双指自由缩放平移并集画幅，以及 `-1 ~ 1` 等亮线性相对透明度调节。
  * **独立水平镜像**：左右视频均支持独立水平翻转，无缝适配前置摄像头拍摄或镜像扒技。
* **BPM 自动测算与对拍锚点对齐**：
  * 导入后自动检测音频波形与初始 BPM（支持手动修正），支持结合波形图与逐帧微调手动打下唯一对拍锚点。
  * 支持「不对齐 BPM（同速对拍）」与「自选 BPM 对齐（按左视频 BPM / 按右视频 BPM / 手动输入目标 BPM）」。
* **0.1x 超慢放与精准节拍器**：
  * 支持 `0.1 / 0.15 / 0.2 / 0.3 / 0.5 / 0.75 / 1.0` 七档慢放与逐帧步进。
  * 默认按对齐后的有效 BPM 与锚点相位播放精准合成节拍器，也可切换为单侧原视频音轨（全程开启变速不变调，超慢倍速不自动静音）。
* **所见即所得视频导出**：固定按两视频对齐后的并集时间区间，将当前预览模式、视口位置、慢放倍速与所选音轨直接合成为 MP4 视频。
