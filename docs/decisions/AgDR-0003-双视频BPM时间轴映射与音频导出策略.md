# 双视频统一时间轴映射、合成节拍器与并集区间导出策略

> 在对比两个不同起拍时间、不同原始 BPM 的视频并进行 0.1x~1.0x 慢放和导出时，面对超慢放下原音乐瞬态模糊以及两视频时长不一致的问题，我决定以“对拍锚点 + 目标 BPM 变速比”建立统一时间轴，默认使用对齐后的 BPM 播放合成节拍器（可选切换单侧变速不变调音轨且超慢放不静音），并固定按两视频对齐后的并集区间进行所见即所得导出。

## 考虑过的方案

| 方案 | 好处 | 代价 |
| --- | --- | --- |
| 自动测算BPM（可手改）+ 手动波形打锚点 + 默认BPM节拍器/可选单侧音轨 + 并集区间导出 | 0.1x 超慢放下节拍器依然清脆精准；保留单侧变速不变调原声满足听歌需求；并集导出不丢失任何一侧的起手准备或收尾动作 | 需要实现前端音频节拍检测算法、WebAudio 节拍器合成以及并集区间单侧越界时的首尾帧/黑底处理 |
| 仅播放原视频混音 + 0.3x 以下自动静音 + 交集区间导出 | 实现简单，无需合成节拍器音轨 | 0.3x 以下无任何声音反馈导致无法卡拍；交集导出会截断较长视频的首尾动作 |

## 决定

选 **自动测算BPM（可手改）+ 手动波形打锚点 + 默认BPM节拍器/可选单侧音轨 + 并集区间导出**，具体数学与音频规则如下：
1. **原始 BPM 与对拍锚点**：导入视频后通过音频能量包络/自相关算法自动测算 $\text{BPM}_1, \text{BPM}_2$（用户可手动修改）；用户在两个视频中各自手动指定唯一对拍锚点时间戳 $t_{1,0}, t_{2,0}$。
2. **统一时间轴映射**：
   - 设全局对比时间轴相对于对拍锚点的偏移时间为 $\tau$（$\tau = 0$ 即两视频的对拍锚点时刻），当前慢放倍率为 $k \in \{0.1, 0.15, 0.2, 0.3, 0.5, 0.75, 1.0\}$。
   - 当选择「不对齐 BPM」时，两视频相对速率比 $r_1 = 1, r_2 = 1$；当选择「自选 BPM 对齐」并指定目标 $\text{BPM}_{\text{target}}$（取 $\text{BPM}_1$、$\text{BPM}_2$ 或手动值）时，$r_1 = \frac{\text{BPM}_{\text{target}}}{\text{BPM}_1}, r_2 = \frac{\text{BPM}_{\text{target}}}{\text{BPM}_2}$。
   - 在统一时间轴偏移 $\tau$ 处，视频 $i$ 对应的源视频时间戳为：
     $$t_i(\tau) = t_{i,0} + \tau \cdot r_i$$
   - 实际播放时，视频 $i$ 的播放倍速设为 $k \cdot r_i$。
3. **并集时间区间**：
   - 视频 $i$ 映射到统一时间轴上的起止范围为 $[\tau_{i,\text{start}}, \tau_{i,\text{end}}] = [-\frac{t_{i,0}}{r_i}, \frac{D_i - t_{i,0}}{r_i}]$（其中 $D_i$ 为视频 $i$ 总时长）。
   - 播放与导出的完整时间轴固定取两者的**并集区间**：
     $$[\tau_{\min}, \tau_{\max}] = [\min(\tau_{1,\text{start}}, \tau_{2,\text{start}}), \max(\tau_{1,\text{end}}, \tau_{2,\text{end}})]$$
4. **声音与导出合成**：
   - 默认以 $\tau = 0$ 为第 0 拍相位原点，按有效节拍间隔 $\Delta \tau_{\text{beat}} = \frac{60}{\text{BPM}_{\text{effective}}}$ 触发 WebAudio 合成节拍器（导出时同样将该节拍器或所选单侧变速不变调音轨混流写入 MP4）。

## 代价

- 我们接受：前端需实现离线音频 PCM 分析、节拍器脉冲合成以及导出时的音视频同步编码。
- 我们放弃：不在播放页增加额外的 A-B 裁剪滑块，保持界面精简。
- 后面要还的债：若两个视频长度相差悬殊导致并集过长，后续可根据实际练技反馈再评估是否需要快捷跳过空白段。

## 什么情况下需要重新讨论

- 如果用户在导出 0.1x 超慢放时发现并集区间首尾准备时间过长、严重拖慢导出耗时，重开这条记录评估是否增加首尾空白裁切。
