# 移动端全屏视口层级精简与单轴导出交互重构

> 在移动端横屏环境下（可用逻辑高度仅 360px~450px），面对多层横栏挤压视频核心视口、BPM 与锚点信息在同一页面上下重复冗余、BPM 对齐过早决策、对比台工具栏长期占高、以及导出台双滑块割裂且预览失效的问题，我决定：
> 1. 彻底删除空间标定（02/03）与对拍（04/05）的第二行工具栏，将模型选择与镜像开关收纳至主顶栏右上角，释放纵向高度让视频铺满上下；
> 2. 清除全流程冗余信息与不统一称谓，顶栏 BPM 仅在对比台展示，移除对拍顶栏锚点，统一全软件所有通道标识为 CH1 与 CH2，移除顶栏步骤数字标号；
> 3. 将 BPM 对齐策略移入对比台右下角，改造为向上弹出的选择菜单；对比台顶部工具栏默认收起，点击对比台标签自由收展；
> 4. 将「导出片段」升级为顶栏直达步骤，导出 A-B 起止时间统一在单根交集时间轴上标定并移除全片按钮，预览播放复用对比台音视频同步引擎；
> 以达成移动端极致大画面、单一真实源、零冗余、直观可靠的 WOTA 艺扒技体验，并接受部分高级选项被收起需要点开查看的代价。

## 考虑过的方案

| 方案 | 好处 | 代价 |
| --- | --- | --- |
| **方案 A：保持双层横栏，仅缩小按钮与间距** | 代码改动量最小，所有功能始终平铺在外 | 移动端横屏下高度被吃掉 80px，视频只能缩在狭窄的中间缝隙，核心动作与挥棒细节严重看不清 |
| **方案 B：将所有控制项收入底部浮动抽屉或二级弹窗** | 画面可以完全全屏 | 操作链路变长，频繁微调标定或切换模式时需要反复打开/关闭抽屉，违背现场扒技即时反馈原则 |
| **方案 C（入选）：顶栏动态插槽 + 工作台折叠栏 + 单轴导出与同步引擎复用** | 空间与对拍实现真正的满高铺满，关键信息仅保留单一真实源；对比台默认大画面且支持一键点展；导出操作直观且声画同步可靠 | 对比台工具栏默认收起，初次使用的用户需知道点击对比台即可展开；移除全片按钮后需手动拖拽区间 |

## 决定

选 **方案 C**，因为：
1. **第一性原理与视觉视口**：WOTA 艺慢放扒技的核心价值在于视频本身的动作与光弧细节，在 360px~450px 的横屏设备中，多一栏 40px 的工具栏意味着损失约 10%~12% 的视口高度。必须坚决把垂直空间归还给视频；
2. **单一真实源（Single Source of Truth）**：同一屏幕内相同信息（如 BPM、锚点时间戳）多处显示极易造成认知负担。对拍步骤由底栏统一承载输入，顶栏仅在对比台呈现整体对齐状态；
3. **决策链路合理化**：BPM 对齐是双视频同台时的决策，在单视频对拍时尚未看到双人同台效果，无法准确判断该随 CH1、随 CH2 还是微调原速。移入对比台右下角符合实际使用心智；
4. **单轴直观性与预览可靠性**：导出本质是截取交集时间轴的一段子区间，在同一根轴上标定 IN 与 OUT 最符合非线性编辑直觉；复用对比台经过验证的双视频同步播放循环彻底解决预览黑屏卡顿。

## 代价

- 我们接受：对比台初始进入时工具栏处于折叠状态，需要切换模式或声音源时需点击一下顶栏「对比台」展开；
- 我们放弃：在导入界面使用「基准源」「对比源」等定性称谓，放弃顶栏的 `01`~`06` 数字前缀；
- 我们放弃：导出页的「全片」快捷按钮，起止时间均在单根轴上拖动或点击当前游标赋值；
- 后面要还的债：如果未来顶栏步骤进一步增加，需要支持在极窄手机上横向平滑滑动或分段滚动指示。

## 什么情况下需要重新讨论

- 如果用户反馈在某些超窄屏设备上顶栏 7 个短标签仍然产生折行或显示不全，需进一步重开讨论分级折叠或图标化呈现。
