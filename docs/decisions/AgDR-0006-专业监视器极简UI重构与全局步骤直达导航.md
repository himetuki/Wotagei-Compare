# 采用专业影视监视器极简暗黑设计系统、全局步骤直达条与精简只读参数导出页

> 在三线正交锚定模型已统一但前端仍残留内联五彩样式、泛滥 Emoji、自嗨宣传文案、冗余演示按钮与重复参数面板的处境下，面对横屏可视面积紧张与导航入口割裂的顾虑，我决定采用集中式 CSS 变量的专业影视监视器极简暗黑 UI、顶部全局步骤分段直达条以及继承工作台参数的精简导出页，以达成零视觉噪音、一步直达微调与最高监看画幅占比，并接受移除内置演示生成器和导出页二次调参表单的代价。

## 考虑过的方案

| 方案 | 好处 | 代价 |
| --- | --- | --- |
| 专业监视器极简暗黑 CSS 体系 + 顶部全局步骤直达条 + 精简独立导出页 | 纯黑/深炭灰底色与单一强调色让视频光弧与标尺线成为唯一视觉焦点；顶部步骤条把向导流转与单项微调合二为一；导出页不再重复工作台已有开关，专注 A-B 区间裁剪 | 移除内置 Demo 生成按钮，导出前若需切换模式或倍速需在工作台完成 |
| 保留内联样式仅做局部颜色替换与文案微调 | 改动文件少 | 無法根治冗余按钮、下拉框导航割裂、SVG 标尺文字非等比拉伸变形与导出页控件重复堆砌的问题 |
| 将 A-B 裁剪与导出全部塞入播放工作台底部控制栏 | 少一个独立视图 | 移动端横屏底部控制栏高度受限，再叠加上 A-B 起止滑块会严重挤压对比播放画幅 |

## 决定

选 **专业监视器极简暗黑 CSS 体系 + 顶部全局步骤直达条 + 精简独立导出页**，因为：
1. **视觉降噪与组件收敛**：在 `src/index.css` 集中定义监视器色彩与控件类（`#000000` 画布底、`#09090b` 栏底、`#18181b` 表面、`#27272a` 1px 细边框、`#f59e0b` 琥珀主强调色、`tabular-nums` 等宽数字时间码），彻底清除全部 Emoji 与自嗨式副标题小字。
2. **导航与状态机合一**：既然三线正交锚定已统一（见 AgDR-0005），导入页无需选择初始对比模式，且不再需要 `patchingStep` 补标定分支与 `standaloneEdit` 下拉框。顶部统一渲染 6 步分段直达条（`01 导入` / `02 视频1空间` / `03 视频2空间` / `04 视频1对拍` / `05 视频2对拍` / `06 对比台`），双视频导入后任意步骤均可一键点击直达。
3. **三线标定层解耦 SVG 变形**：废弃 `preserveAspectRatio="none"` SVG `<text>` 渲染，改用精确追踪视频实际显示矩形的 HTML/CSS 标尺线与定宽角标，确保标尺在任意视频宽高比下锐利且不拉伸。
4. **导出页单一职责**：`ExportPage` 直接读取工作台传入的 `mode`、`mirror1/2`、`slowMotionRate`、`soundSource`、`relativeOpacity` 与 `viewport`，仅提供单帧预览、A-B 区间截取与导出执行，删除未使用的 `ExportModal.tsx` 与 `demoGenerator.ts`。

## 代价

- 我们接受：移除 `src/core/demoGenerator.ts` 与 `src/components/ExportModal.tsx`，并重写全部 5 个前端视图组件的 DOM 与样式结构。
- 我们放弃：不在导出页提供二次修改对比模式、倍速、音源的冗余表单，不在导入页提供一键生成测试视频按钮。
- 后面要还的债：无。

## 什么情况下需要重新讨论

- 如果后续需要支持批量队列导出多组不同倍速/不同音源的对比切片时，再重开这条记录评估导出预设列表。
