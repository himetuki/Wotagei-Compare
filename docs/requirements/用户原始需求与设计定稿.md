# Wotagei-Compare 用户原始需求与设计定稿

> 本文件记录用户原始需求及首轮 Grilling 访谈达成的完整设计定稿，作为项目只读需求基线。

## 一、原始需求描述

WOTA 艺的进阶需要向高手学习，但是光对着视频看是看不出来东西的，光对着镜子扣也很容易忽略自己细节之处的问题。最好的办法其实是把自己的视频和高手的视频放到一起做同台对比，然后慢放下来逐步学习高手的卡拍和细节等等。然而，现在的问题是，我们必须等每次打完回家后才能慢慢对着高手的视频剪辑，而且剪辑完后那一瞬间的感悟到了下一次练习又消散了。换而言之，迭代效率太低。

因此需要制作一个手机软件，能导入高手视频和自己的练习视频，并做对比播放。核心需求如下：

1. 能导入两个视频
2. 支持两种播放模式：左右分区和半透明叠加
3. 考虑到手机屏幕大小，对于左右分区模式而言，在导入视频后，可以通过框出视频内的人物来进行自动的缩放
4. 对于半透明叠加模式而言，在导入视频后，可以通过在视频中点出锚点/基准线来锚定位置并确定相对缩放比例
5. 半透明叠加模式可以选择相对透明度（-1~1）
6. 支持两个视频的 BPM 对齐。分两种类型：一种是不对齐（仅设置唯一对齐点），另一种是自选 BPM 对齐（两视频 BPM 统一到一个速度，支持按左视频 BPM、按右视频 BPM 和自行手动填写）
7. 支持慢放（0.1 / 0.15 / 0.2 / 0.3 / 0.5 / 0.75 / 1）
8. 支持导出视频

## 二、Grilling 设计定稿细则

### 1. 运行载体与屏幕方向
- **目标载体**：原生跨平台 App（Android 优先），采用 React + TypeScript + Canvas/WebCodecs/WebAudio + Capacitor 原生 Android 壳封装。
- **屏幕方向**：**强制全程横屏（Landscape）**，确保左右分区和全屏标定都具备充足的横向挥棒视野。
- **画面辅助**：左右两个视频均提供独立的**水平镜像翻转**开关（解决前置摄像头拍摄或镜像扒技需求）。

### 2. 线性向导式对齐流程（先图像后音频，均先一后二）
导入两个视频并选定初始对比模式（左右分区 / 半透明叠加）后，按单视频全屏逐个标定的线性向导推进：
1. **图像对齐 - 视频 1**：全屏显示第一个导入的视频，可拖动时间轴寻找标准站姿帧、可切换水平镜像。
   - 若为「左右分区」模式：单次手绘/调整一个固定矩形裁剪框（包含人物与挥棒半径）。
   - 若为「半透明叠加」模式：采用**三线正交锚定法**，由用户二选一：
     - **两条横线 + 一条竖线**（适合两人站宽不同、重点对齐头顶与裆部等上半身动作及身体中轴线）；
     - **两条竖线 + 一条横线**（适合两人站宽相近、重点对齐双脚站位与地面高度）。
2. **图像对齐 - 视频 2**：全屏显示第二个导入的视频，同样支持找帧与水平镜像，完成对应模式的矩形框或同类型三线正交标定。
3. **音频/时间对齐 - 视频 1**：自动利用算法从音轨测算初始 BPM 填入输入框（支持手动修改）；展示视频画面 + 底部音频波形图 + 逐帧微调按钮，用户定位到起拍帧后手动设为**视频 1 对拍锚点**，并在波形上显示基于当前 BPM 与锚点生成的节拍刻度线供试听校验。
4. **音频/时间对齐 - 视频 2 & BPM 对齐策略**：自动测算视频 2 初始 BPM（支持手动修改），通过画面 + 波形图 + 逐帧按钮手动设定**视频 2 对拍锚点**；同时选择 BPM 对齐策略（不对齐 BPM / 按视频 1 BPM / 按视频 2 BPM / 手动填写目标 BPM）。

### 3. 同台对比播放与视口规则
- **左右分区模式**：将视频 1 和视频 2 各自标定的矩形框自动等比居中放大，分别填满左半屏和右半屏。
- **半透明叠加模式**：
  - 利用三线正交锚定（两条平行线间距比决定等比缩放率 $s$，两平行线中点与正交线交点决定平移量 $\Delta x, \Delta y$，不旋转画面）将视频 2 对齐到视频 1 坐标系。
  - 默认居中适配显示两视频对齐后的**并集画幅**，并在播放页支持**双指自由缩放与平移**观察局部细节。
  - **相对透明度 $p \in [-1, 1]$**：按权重 $\frac{1-p}{2}$ 与 $\frac{1+p}{2}$ 进行等亮线性混合（$p=-1$ 为纯视频 1，$p=0$ 为 50%:50% 等亮叠加不发暗，$p=+1$ 为纯视频 2）。
- **播放页模式切换**：在播放页切换到另一尚未标定的模式时，自动弹出补标定流程补齐该模式所需的矩形框或三线，标定后即可随时无缝切换。

### 4. 慢放、逐帧与声音策略
- **慢放档位**：支持 `0.1 / 0.15 / 0.2 / 0.3 / 0.5 / 0.75 / 1.0` 倍速，以及暂停时的**上一帧 / 下一帧逐帧微调**。
- **声音控制**：
  - **默认声音**：按对齐后的有效 BPM（结合当前慢放倍率）与对拍锚点相位播放精准**合成节拍器**。
  - **可选切换**：支持切换为单侧原视频音轨（仅视频 1 音轨 / 仅视频 2 音轨 / 静音），原视频音轨**始终开启变速不变调**，超慢倍速下**不自动静音**。

### 5. 视频导出规格
- **时间范围**：固定导出两视频对齐后的**并集时间区间**。
- **导出方式**：**所见即所得导出**——严格按照当前播放页的画面模式（左右分区或半透明叠加、当前视口缩放/平移位置、当前相对透明度）、当前慢放倍速、以及当前选定的声音源（合成节拍器或单侧变速不变调音轨）合成为 MP4 视频保存。
