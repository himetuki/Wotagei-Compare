# Spec Delta

## MODIFIED Requirements

### Requirement: 同步音频混流与 MP4 编码
系统 MUST 将用户选定的声音配置（合成节拍器、视频 1 原声、视频 2 原声或静音）离线渲染为音频流，与离线渲染的视频帧通过确定性时间戳（PTS）管线（在 Android 原生平台通过原生 `MediaCodec + OpenGL ES + MediaMuxer` 管线，在现代 Web 浏览器通过 WebCodecs + `mp4-muxer` 管线）合成为标准的 MP4 容器文件；当声音源为合成节拍器时，离线音频合成算法 MUST 严格以 $\tau = 0$ 对应导出时间点锁定小节第 1 拍重拍（$k \equiv 0 \pmod 4$），采用绝对拍号整数步进消除浮点累加误差，且在波形能量与音色响度包络上与实时节拍器保持完全一致，达到匹敌 -5.9 LUFS 级别伴奏的充沛响度；导出的成片物理播放总时长 MUST 精确等于截取区间除以慢放倍率（即 `(clipEnd - clipStart) / slowMotionRate`），严禁受离线渲染过程消耗的物理挂钟时间影响；视频与音轨在整个导出成片中 MUST 保持严格的毫秒级声画同步与同等播放时长。

#### Scenario: 导出携带合成节拍器声音
- **WHEN** 当前声音源为合成节拍器并执行视频导出
- **THEN** 生成的 MP4 文件包含与画面动作精准对齐的高响度节拍器音频轨，在外部播放器播放时声画完全同步，且对齐锚点 $\tau = 0$ 处精准响起小节重拍，整段音频音量充足、清脆不爆音

#### Scenario: 慢放导出成片时长与物理挂钟解耦
- **WHEN** 用户在导出工作台截取 3 秒的交集区间并设定 0.25x 慢放执行导出
- **THEN** 无论离线合成与编码在物理设备上实际消耗了多长时间，最终导出的 MP4 视频时长严格等于 12 秒（3 / 0.25 秒），且全片以均匀设定的帧率流畅播放，耗时显著快于实时播放等待时间（无物理挂钟绑死限制）

#### Scenario: 导出携带单侧视频原声音轨
- **WHEN** 用户选择 CH1 原声或 CH2 原声作为导出声音源并执行导出
- **THEN** 系统离线提取对应通道在截取区间内的音频采样数据，按统一时间轴速率比与慢放倍率变速重采样后写入导出的 MP4 文件，外部播放器播放时包含正常清晰的伴奏声音，声画完全对齐

### Requirement: 移动端系统相册保存
在原生 Android 应用环境下，系统 MUST 在原生编码完成后直接将生成的 MP4 文件写入系统公开的「Movies / 相册」目录并触发系统媒体库扫描入库，同时界面明确提示保存路径；仅纯 Web 浏览器环境提供浏览器文件下载链接，Android 原生端严禁依赖无效的 `blob:` 链接下载或全量 Base64 跨桥文件拷贝。

#### Scenario: 导出完成保存相册
- **WHEN** MP4 视频在 Android 原生壳中编码完成
- **THEN** 系统将 MP4 文件直接落盘至系统公开相册目录并通知媒体库入库，界面直接展示保存成功路径，用户打开系统相册即可直接浏览与分享该对比慢放视频

## ADDED Requirements

### Requirement: Android 原生全机型 GPU 零拷贝离线 MP4 导出
在 Android 原生平台上（API 23+），无论系统 WebView 内核版本新旧（含缺少 WebCodecs 的 Chrome 70~93），系统 MUST 统一通过原生硬件解码与 GPU 离线编码管线输出标准 `.mp4` 文件。前端与原生层之间 MUST 仅传递纯 JSON 布局、时间轴及音频合成参数，严禁跨桥传输视频帧像素、大体积 Base64 或全量 PCM 数组；原生层在慢放重复帧区间 MUST 直接复用 GPU 纹理并递增展示时间戳（PTS），使老版本手机也能以显著快于实时回放的速度完成导出。

#### Scenario: Chrome 74 老版本 Android 10 设备离线高速导出 MP4
- **WHEN** 用户在无 `VideoEncoder` 的 Android 10（Chrome 74 WebView）上截取任意有效 A-B 区间（如 0.2x 慢放 6 秒原片得到 30 秒成片）并点击「开始渲染导出」
- **THEN** 系统无需实时等待 30 秒录制回放，进度稳定推进至 100%，最终生成非空且可正常播放的标准 `.mp4` 文件并写入系统相册，全程不出现兼容模式 `.webm` 实时录制提示

#### Scenario: 老版本设备导出页面标签与能力一致性
- **WHEN** 用户在 Android 原生设备上进入「导出片段」页面
- **THEN** 顶部规格徽章展示标准 `.mp4` 输出参数，不展示「兼容模式将实时录制导出 WebM」提示

## REMOVED Requirements

### Requirement: 老旧 WebView 无 WebCodecs 时兼容录制导出降级
**Reason**: 基于 `MediaRecorder` + `canvas.captureStream` 的降级路径强制绑定物理挂钟时间（`0.1x` 慢放导出需等 10 倍物理时长），仅能输出 `.webm`，且在老设备上存在 Base64 跨桥写入 OOM 与 WebView `blob:` 下载失效缺陷。
**Migration**: Android 原生平台下全部老旧与现代机型统一迁移至「Android 原生全机型 GPU 零拷贝离线 MP4 导出」；桌面 Web 调试使用现代浏览器 WebCodecs 管线。
