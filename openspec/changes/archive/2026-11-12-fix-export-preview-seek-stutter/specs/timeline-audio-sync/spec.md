# Spec Delta

## MODIFIED Requirements

### Requirement: 绝对主时钟与 PLL 锁相环同步引擎
在播放工作台播放时，系统 MUST 以发出声音的视频硬件时间戳作为全局唯一的绝对主时钟，并对从属视频应用 PLL 锁相环进行速度微调平滑追赶；系统 MUST 具备起播就绪防抖栅栏与寻道互斥机制，严禁在视频处于异步寻道未完成状态（`seeking === true` 或 `readyState < 2`）期间对其重复设置 `currentTime`；对严重失步场景下的单次硬对齐跳转 MUST 引入至少 600ms 的冷却隔离保护，严禁在播放循环中连续相邻帧强行反复 seek 导致卡顿黑屏与声画延迟。

#### Scenario: 声画绝对零延迟播放
- **WHEN** 用户选择单侧原视频音轨进行播放
- **THEN** 发声视频作为绝对主时钟驱动声画零延迟输出，另一路视频以微小调速平滑贴合，两视频同频锁死

#### Scenario: 对比台大跨度拖拽进度条后平滑起播
- **WHEN** 用户在对比工作台中快速拖动时间轴进度条至新时刻并立即点击「播放」
- **THEN** 系统检测双端视频就绪状态并等待双方完成寻道后联合起播，从属视频在追赶过程中不触发重复中断寻道，双视频画面在 100ms 内平滑同频推进，无单侧死锁卡滞

#### Scenario: 对比台播放中持续滑动进度条防雪崩
- **WHEN** 对比台处于连续播放状态，用户在时间轴进度条上进行连续拖动
- **THEN** 系统对寻道事件进行节流控制，不向正在寻道的视频重复推送新时间戳，并在寻道完成后平稳恢复双通道播放
