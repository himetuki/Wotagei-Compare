# Spec Delta

## MODIFIED Requirements

### Requirement: 所见即所得画布逐帧离线合成与实时单帧预览
系统在导出工作台中 MUST 提供画布预览，并在预览栏内提供「预览 / 暂停」控制按钮，复用对比工作台的双视频音画硬件时间戳同步驱动引擎；在预览播放期间，系统 MUST 依据所选声音源（CH1 原声、CH2 原声、合成节拍器或静音）实时发声并支持变速不变调；当用户在暂停或播放状态下拖拽进度条、或拖动后立即触发播放时，系统 MUST 具备寻道互斥与起播就绪防抖机制，严禁在视频处于寻道未就绪状态（`seeking` 或 `readyState < 2`）时进行高频重复硬赋值（Seek Thrashing）；系统 MUST 实现从属通道防雪崩锁相环追赶控制，且在播放状态下拖动时间进度条 SHALL 重新定位至目标时刻并保持双侧平滑推进播放，严禁触发单侧画面卡死或自动暂停；离线导出时 MUST 严格复用对比工作台的几何与时间轴变换参数。

#### Scenario: 保持当前视口缩放与透明度导出
- **WHEN** 用户在播放工作台设定 0.2x 慢放后进入导出工作台并点击导出
- **THEN** 导出的 MP4 视频画面与工作台预览呈现完全一致的视野、透明度比例与 0.2x 慢放速度，无任何坐标或缩放偏离

#### Scenario: 导出台内连续播放预览
- **WHEN** 用户在导出工作台点击画布下方的「预览」按钮并在播放中点击或拖动时间进度条
- **THEN** 系统按当前设定倍速平滑连续呈现双视频合成画面并输出对应音轨或节拍器声音，跳转到目标时刻后画面与声音不中断、继续平滑推进播放，按钮保持为「暂停」状态

#### Scenario: 拖动进度条后立即播放双侧流畅无卡顿
- **WHEN** 用户在导出工作台拖动预览时间进度条至任一交集时刻，并在 100ms 内快速点击「预览」开始播放
- **THEN** 系统等待双视频均完成寻道并进入可渲染就绪状态后同步启动时钟与画面渲染，双侧视频均平稳起播，不存在任一单侧画面冻结、疯狂重寻道掉帧或剧烈顿挫现象

#### Scenario: 播放中连续高频拖动进度条防雪崩
- **WHEN** 导出工作台处于预览播放状态，用户连续高频滑动时间滑块或快速点击定位
- **THEN** 系统对寻道请求进行节流保护，不向处于寻道中的视频重复推送新时刻，寻道完成后立即恢复平滑同步，双通道视频保持同频播放与音画对齐
