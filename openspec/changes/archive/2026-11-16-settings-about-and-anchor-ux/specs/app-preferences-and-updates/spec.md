# Spec: app-preferences-and-updates

## ADDED Requirements

### Requirement: 默认工作流偏好配置与持久化
系统 MUST 提供默认工作流偏好设置与本地持久化能力，涵盖默认三线模式、默认对比模式、默认音乐播放（声音源）、默认 BPM 对齐策略（含手动目标 BPM）、默认慢放倍速、默认步进粒度以及自定义步进秒数（≥ 0.005s）。冷启动时系统从本地存储读取该组默认值；用户在设置页更改后立即持久化保存，并实时同步更新当前会话中尚未被用户手动改动过的对应状态。

#### Scenario: 修改默认偏好并跨重启保留
- **WHEN** 用户在设置页将默认三线模式设为「两竖一横」、默认对比模式设为「半透明叠加」、默认音乐播放设为「视频1」、默认慢放倍速设为 `0.5x`、默认步进粒度设为「自定义 `0.04s`」并重新加载应用
- **THEN** 应用重启后设置页与各工作流初始状态均保持用户保存的默认参数

#### Scenario: 未手动改动的当前会话状态实时同步
- **WHEN** 用户导入视频后尚未在对比台手动切换过对比模式或声音源，先进入设置页修改默认对比模式为「半透明叠加」并切回推进到对比台
- **THEN** 对比台自动应用新修改的「半透明叠加」默认模式；若用户此前已在对比台手动改选过对比模式，则保留用户会话内的手动选择不被覆盖

### Requirement: 自定义步进秒数自由编辑与失焦规整
设置页与对比台中的「自定义步进粒度」秒数输入框 MUST 允许用户在编辑期间自由键入或清空数字（不逐字强制重写），并在失去焦点或按下回车时钳位至最小 `0.005s` 后格式化为三位小数（`toFixed(3)`）；非法或空输入回退恢复为当前有效值。

#### Scenario: 自定义步进秒数自由输入与失焦格式化
- **WHEN** 用户在设置页选中「自定义」步进粒度并将秒数框清空后输入 `0.04`，再点击框外失去焦点
- **THEN** 输入期间光标与数字不被强制改写，失焦后框内自动格式化显示为 `0.040` 并生效为默认自定义步进秒数

### Requirement: GitHub 仓库信息展示与直达跳转
设置与关于页面 MUST 展示应用图标、软件名称、当前版本号、开源协议及项目说明，并提供 GitHub 仓库主页（`https://github.com/jollyxenon/Wotagei-Compare`）与 Releases 页面跳转操作，点击后在外部浏览器或新标签页打开目标地址。

#### Scenario: 从设置页跳转 GitHub 仓库
- **WHEN** 用户点击设置与关于页面中的「GitHub 仓库」按钮
- **THEN** 系统打开 `https://github.com/jollyxenon/Wotagei-Compare` 页面供查看源码与发行说明

### Requirement: 跨平台版本检查与 Android 端内 APK 更新安装
设置与关于页面 MUST 提供「自动更新 / 检查更新」按钮，查询 GitHub Releases 最新版本并与当前版本比对。若已最新则提示无需更新；若发现新版本，Web 与桌面端展示更新说明并提供 Releases 下载跳转；Android 原生端 MUST 支持端内流式下载 `.apk` 资产并实时展示进度百分比，在缺少安装权限时引导跳转系统未知应用安装授权页，就绪后拉起系统包安装器完成更新。

#### Scenario: 检测远端无新版本
- **WHEN** 用户点击检查更新按钮且 GitHub Latest Release 版本号不高于当前应用版本
- **THEN** 页面显示当前已是最新版本的提示，不启动下载流程

#### Scenario: Android 端发现新版本并端内下载安装
- **WHEN** Android 原生端检测到高于当前版本的 GitHub Release 且包含 `.apk` 安装包，用户确认下载更新
- **THEN** 应用在私有缓存目录下载最新 APK 并实时刷新进度百分比，具备安装权限后通过 FileProvider 调起系统安装器界面；若请求或下载失败则展示明确中文错误反馈而不阻塞既有功能

### Requirement: Android 更新安装包自动清扫
在 Android 原生平台下，系统 MUST 仅将下载的更新安装包以 `wotagei_update_*.apk` 命名保存于应用私有缓存目录，并在每次插件冷启动初始化、每次启动新下载前以及安装界面取消或失败返回当前进程时自动清理遗留的安装包文件。

#### Scenario: 更新安装完成后重启自动删除安装包
- **WHEN** 用户通过端内更新安装新版 APK 后重新启动应用
- **THEN** 应用启动初始化时自动扫描并删除私有缓存目录中的 `wotagei_update_*.apk` 文件，不残留历史安装包占用存储

#### Scenario: 取消安装或再次下载前清理旧安装包
- **WHEN** 用户在系统安装确认界面点击取消返回应用，或再次点击下载新版本 APK
- **THEN** 先前下载的 `wotagei_update_*.apk` 安装包立即被清理删除
