# Spec Delta

## MODIFIED Requirements

### Requirement: 全量统一为三线正交锚定空间标定
系统 MUST 全量采用三线正交锚定模型（「两横一竖」或「两竖一横」二选一）作为唯一的空间标定体系；标定模型（「两横一竖」与「两竖一横」）在 CH1 与 CH2 空间标定页面中 MUST 保持全局同步，共用同一个状态变量与顶栏下拉控件，在任意一个空间切换模型后，另一个空间 SHALL 自动保持该模型；空间标定页面彻底移除原上方第二行工具栏，将画面区域纵向放大填满上下空间；标定模型选择升级为下拉菜单并迁移至顶栏右上角，文案为「两横一竖」与「两竖一横」；镜像开关亦迁移至顶栏右上角；三线标定角标文字 SHALL 仅显示纯文本角色标签并移除百分比数值；两横一竖模型下，头顶黄线角标 MUST 置于黄线左下方，脚底绿线角标 MUST 置于绿线右上方以避免底部进度条遮挡；空间标定底部控制栏仅保留播放/暂停与时间轴滑块，移除 `< 1F` 与 `1F >` 步进按钮。

#### Scenario: 两横一竖模型标定
- **WHEN** 用户在顶栏下拉菜单中选择「两横一竖」模型并在视频画幅内拖拽两条横线贴合头顶与脚底、一条竖线对齐身体中轴
- **THEN** 系统记录两条横线与竖线坐标，头顶标签显示于黄线左下方，脚底标签显示于绿线右上方，角标不显示百分比数值，画面纵向填满顶部导航栏与底部控制栏之间的全部可用视口，切换至另一通道时该通道亦自动同步为两横一竖模型

#### Scenario: 两竖一横模型标定
- **WHEN** 用户在顶栏下拉菜单中选择「两竖一横」模型并在视频画幅内拖拽两条竖线分别贴合左右脚外侧、一条横线贴合地面接触线
- **THEN** 系统记录两条竖线归一化 X 坐标与横线归一化 Y 坐标，标尺角标仅显示中文角色名称不显示百分比，切换至另一通道时该通道亦自动同步为两竖一横模型

#### Scenario: 空间标定控制栏精简
- **WHEN** 用户处于视频空间标定页面
- **THEN** 界面不显示上方第二行工具栏，视频画幅放大填满上下视口，底部控制栏不显示 1F 逐帧微调按钮，仅提供播放/暂停与时间轴拖动定位
