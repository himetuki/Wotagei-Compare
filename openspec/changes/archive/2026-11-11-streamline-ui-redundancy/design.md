# Design: streamline-ui-redundancy

## Context

见 [proposal.md](./proposal.md) 的背景说明。
在真实 Android 横屏实机运行中，屏幕可用逻辑宽度仅为 650px~850px（受右侧金刚键及系统缩放影响）。当前代码中，顶栏常驻重复的 BPM 徽章并采用 4 字步骤长名称，音频对拍与工作台底栏平铺排布了 13 个以上不可收缩的控件，导致整行总宽度超过 850px，在实机上发生严重的横向溢出截断——顶栏最右侧「下一步」按钮消失、对拍底栏最右侧 BPM 调整输入框被切掉一半、工作台「导出片段」被金刚键覆盖。

## Goals / Non-Goals

**Goals:**
- 彻底剔除界面一切重复状态展示，落实“单一状态唯一点位管理”，删除顶栏冗余的 `CH1/CH2 BPM` 徽章。
- 将顶部 6 步直达导航标签从「02 视频1空间」等冗长文字精简为「02 空间1」「04 对拍1」，使导航总宽度从约 450px 缩减至 310px，让出 140px+ 空间。
- 重构音频对拍控制栏，移除对拍阶段冗余的平铺慢放倍速组，整合锚点与微调按钮，确保底栏总宽度控制在 600px 以内，让右侧的 BPM 调整区在任何屏幕下都 100% 完整可见。
- 优化工作台（Workbench）次级工具栏和底栏控件排布，确保「导出片段」按钮与透明度控制滑块完整展露。
- 以自动化 Playwright 移动端仿真环境（`scripts/sim-device.cjs`）作为硬性检验标准，实现修改后的自动截图自检。

**Non-Goals:**
- 不改变底层三线几何标定与双视频时间轴映射核心算法。
- 不引入横向滚动条或破坏专业影视监视器的纯黑极简视觉风格。

## Decisions

### 决策 1：全面剔除冗余状态与精简控件排布
- **决策详情**：
  - 顶栏移除常驻的 `CH1/CH2 BPM` 徽章，仅保留步骤直达与「下一步」核心推进按钮；
  - 步骤直达条字数减半，采用「01 导入 / 02 空间1 / 03 空间2 / 04 对拍1 / 05 对拍2 / 06 对比台」；
  - 对拍页底栏移除多余的慢放组，将「TAP + BPM加减输入」作为当前通道 BPM 的单点唯一操作区；
  - 工作台声音源分段精简为「节拍器 / CH1 / CH2 / 静音」，镜像按钮使用紧凑符号。
- **架构决策记录**：详细推导见 [AgDR-0008: 移动端横向视口紧凑重构与状态冗余全面清除](../../docs/decisions/AgDR-0008-移动端横向视口紧凑重构与状态冗余全面清除.md)。
- **被否决的方案**：
  - *方案 A（横向允许滚动）*：在移动端横向滑动极易误触波形与时间轴，且隐藏在屏幕外的按钮无法建立掌控感。
  - *方案 B（多行折叠堆叠）*：横屏高度极度受限（仅 380px 左右），增加行数会严重压缩中间视频监视核心区。

### 决策 2：建立基于 Playwright 的真机视口自动化仿真闭环
- **决策详情**：在 `scripts/sim-device.cjs` 中配置 853×384、DPR 2.8 真实机型视口，并自动覆盖 72px 真实金刚键层与 32px 状态栏层。在代码修改后自动运行全流程并生成阶段截图，使用 Agent 的 `read` 工具自动审视，绝不盲目交付。

## Risks / Trade-offs

- **[Trade-off] 步骤标签变短是否影响理解**
  → **Mitigation**：向导整体是严格线性的，且「空间1 / 对拍1」相比「视频1空间 / 视频1对拍」语义丝毫不减，但大幅节约了宝贵的横向空间。
- **[Risk] 超小屏（如旧机型横向仅 640px）是否依然可能边缘紧贴**
  → **Mitigation**：所有行容器内部采用 `gap: 4px~6px` 紧凑微调，控件全部具有合理的弹性或固定上限，确保在 640px 极限宽度下仍保留安全边距。

## Migration Plan

1. 更新 `src/App.tsx` 中的 `WIZARD_STEPS` 配置，精简步骤名称并移除顶栏重复的 BPM 徽章。
2. 重构 `src/components/AudioStep.tsx`，精简底栏排布，移除预览倍速组，确保右侧 BPM 步进与输入完整展现。
3. 调整 `src/components/Workbench.tsx`，紧凑化次级工具栏和底栏控件。
4. 运行 `node scripts/sim-device.cjs`，自动截取 4 张视口真机图并使用 `read` 工具逐一审查，确认零溢出与零截断。
5. 重新执行生产构建与 Android 同步。
