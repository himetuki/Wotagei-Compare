# Spec Delta: timeline-audio-sync

## MODIFIED Requirements

### Requirement: 初始 BPM 检测与 Tap BPM 交互测速
系统 MUST 在导入视频后解码音轨并自动测算初始 BPM，同时 SHALL 在音频标定界面提供集成化的「Tap 测速 / 步进微调 / 数值输入」单一真实源控件，用户跟随节拍点按数次即时估算精确整数 BPM，亦支持手动点击加减或直接输入修改，界面严禁在其他区域重复渲染只读的 BPM 状态徽章。

#### Scenario: 连续点击测速
- **WHEN** 用户在音频标定界面随音乐节奏连续点击 Tap 按钮 3 至 4 次
- **THEN** 系统根据点击时间间隔平均值实时换算整数 BPM 并同步填入输入框与节拍指示刻度，不触发任何其他区域的重复镜像刷新

#### Scenario: 连续点击测速与即时调整
- **WHEN** 用户在音频对拍界面随音乐节奏连续点击 Tap 按钮或使用加减步进器
- **THEN** 系统实时更新当前通道的整数 BPM 并即时反映在唯一定位控件中，顶栏及其他区域不出现冗余镜像状态

### Requirement: 交互式音频波形与 60fps 平滑对拍锚点标注
系统 MUST 在音频标定界面以 60fps 帧率平滑驱动播放游标红线，波形图顶部呈现精致节拍刻度，底部控制栏聚焦于播放/暂停、逐帧微调（±1F）、毫秒微调（±20ms）、锚点设定与卡拍试听，严禁堆砌非必要的平铺慢放倍速组，确保全部对拍控件在移动端横屏视口下完整横向容纳。

#### Scenario: 结合慢放与微调精准锚定起拍帧
- **WHEN** 用户在音频对拍界面观察起手动作，定位起拍点并点击微调
- **THEN** 系统更新锚点时间戳，且点击「试听卡拍」时在锚点时刻发出一次高精度敲击脉冲音供声画验收

#### Scenario: 聚焦起拍锚定与无遮挡微调
- **WHEN** 用户在音频对拍界面观察波形起伏与起拍动作并点击微调
- **THEN** 控制栏紧凑呈现核心锚点与微调按钮，最右侧的 BPM 调整区始终完整可见，不发生横向溢出或截断
