# Spec Delta: video-workspace

## MODIFIED Requirements

### Requirement: 模式无缝切换与单项快速微调
系统 MUST 在顶部导航栏提供统一的全局步骤分段直达条，采用紧凑精炼的短标签命名（如 01 导入 / 02 空间1 / 03 空间2 / 04 对拍1 / 05 对拍2 / 06 对比台），确保在移动端横屏狭窄视口下严禁挤占导航空间，当双视频载入后允许用户在任意环节一键直达目标步骤微调参数，并在对比工作台内无缝切换左右分区与半透明叠加模式。

#### Scenario: 快速微调单项参数
- **WHEN** 用户在对比工作台点击顶部步骤条中的「05 对拍2」
- **THEN** 系统直接切换至视频 2 音频对拍视图并展示既有参数，修改后点击顶部「06 对比台」或确认按钮即刻返回工作台

### Requirement: 专业影视监视器极简暗黑视觉规范
系统全界面 MUST 采用纯黑与深炭灰底色、单一高对比主强调色、全矢量几何图标与等宽数字时间码，严禁在任何视图中渲染 Emoji 字符、解释性副标题小字或无交互功能的装饰性按钮；系统 MUST 彻底清除全局状态栏与操作面板中的一切重复状态展示（包括顶栏常驻重复的 BPM 徽章），保证所有核心操作按钮与调整控件在 650px~850px 移动端横屏视口下 100% 完整可见且零横向溢出。

#### Scenario: 界面纯净度与图标检查
- **WHEN** 用户浏览导入页、空间标定页、音频对拍页、对比工作台及导出页
- **THEN** 界面仅呈现矢量图标、精炼控件标签与等宽时间码，不包含任何 Emoji 字符、口号式说明文字或生成演示样本按钮，且顶栏严禁堆砌与当前视图重复的状态徽章

#### Scenario: 狭窄横屏视口零截断检查
- **WHEN** 用户在可用逻辑宽度仅 650px~850px 的横屏设备（含侧边金刚键）上浏览各视图
- **THEN** 顶栏最右侧「下一步」按钮、工作台「导出片段」按钮以及各视图底部操作面板均完整展示，不被挤出屏幕边缘，不发生截断
