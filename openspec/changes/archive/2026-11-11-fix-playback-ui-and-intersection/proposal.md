# Proposal: 移动端播放对比交互优化与时间轴交集重构

## Why

在真机实际测试与用户真实操作体验中，发现若干影响扒技效率与界面观感的体验硬伤：
1. 界面存在冗余或残留装饰物（顶栏无意义的 `WC-MON`、右侧残留的黄色按钮碎片）；
2. 空间标定标注框靠近底部时会被进度条遮挡、百分比数字无实际价值、模型标签括号注释冗余；
3. 音频对拍控制栏拥挤导致关键的 BPM 加减按钮被截断，而用户对微调操作更倾向于直接输入数字而非多级步进按钮；
4. 对比台默认半透明叠加模式不符合双手势对比的第一直觉，镜像图标形状错误（上下翻转误作左右翻转）；
5. 左右半区模式下人物被过度缩小，黑边过大；且双视频采用“并集”导致前后端存在大量单边黑屏无意义区间，起手动作需要“锚点前 1 秒”进行预热观察；
6. 导出台缺乏预览播放控制、右侧面板在横屏下高度溢出导致关键的“开始导出”按钮被截断无法点击。

现在重构这些交互细节，使应用真正契合 WOTA 艺移动端横屏扒技对比的高效实战诉求。

## What Changes

- **顶栏装饰清除与全局可编辑 BPM**：彻底移除左上角无意义的 `WC-MON` 字符；移除全流程顶栏右侧截断残留的黄色按钮；在顶栏常驻可点击编辑的 `CH1 ... BPM` 和 `CH2 ... BPM` 徽章，支持随时随地点击输入修改两通道 BPM。
- **空间标定标签与布局优化**：
  - 将头顶黄线标注框调整至黄线左下方；
  - 将脚底绿线标注框调整至绿线右上方，彻底消除靠近底部时与进度条重叠遮挡的问题；
  - 去除标注框中的百分比显示，仅保留精简的解剖学名称（头顶、脚底、中轴等）；
  - 去除模型选择按钮中的括号注释（精简为「两横一竖」「两竖一横」）；
  - 移除空间标定界面的 `< 1F` 和 `1F >` 步进按钮。
- **音频对拍输入与控制栏重构**：
  - 移除 `< 1F`、`1F >` 以及 `-20ms`、`+20ms` 按钮；
  - 锚点时间改为支持直接点击手动输入精确数值；
  - 释放底部横向空间，确保单一真实源 BPM 微调的 `+` 与 `-` 步进按钮 100% 完整可见不被截断。
- **对比台默认模式、镜像图标与起播点重构**：
  - 对比台初始默认模式变更为「左右分区」；
  - 修正通道镜像翻转按钮图标，替换为正确的左右水平镜像矢量图；
  - 播放控制栏将原「锚点」跳转改为「锚点前 1s 播放」，便于观察起手挥棒动作；
  - 移除对比台底部的 `< 1F` 和 `1F >` 按钮。
- **左右半区分区投影放大**：
  - 调大左右半区模式下的人物三线投影比例（从 42% 放大至 60% 左右），显著缩减黑边，使同台对比画面更加清晰饱满。
- **时间轴与全流程交集重构 (BREAKING)**：
  - **BREAKING**: 统一时间轴映射由视频「并集」全面改为「交集」（仅保留两路视频在锚点对齐后的有效重叠时间段）；超出重叠范围的单边无动作黑屏彻底不进入时间轴与导出区间。
- **导出台全功能补全与横屏溢出根治**：
  - 导出台新增单帧画面的实时播放/暂停预览按钮；
  - 导出台起止区间（A-B 段与全片）全面基于两视频交集范围计算；
  - 修复右侧控制面板在移动端横屏下的垂直溢出问题，重构高度计算与弹性布局，确保成片统计、起止截取与「开始渲染导出」按钮完全展示在主容器内，无遮挡无截断。

## Capabilities

### Modified Capabilities
- `video-workspace`: 移除 `WC-MON` 与顶栏非必要黄色按钮；提供全局可随时点击修改的 CH1/CH2 BPM 徽章；默认进入左右分区模式。
- `geometric-alignment`: 优化三线标注框放置（黄线左下、绿线右上）并去除百分比；精简模型切换文案；修正水平镜像矢量图标；增大左右分区人体特征放大倍率以减少黑边。
- `timeline-audio-sync`: 移除 1F 与 20ms 微调控件；支持锚点数值直接手动输入；确保 BPM 步进按钮完整露出；统一时间轴由并集切换为两视频有效交集（Intersection）；支持锚点前 1s 播放。
- `comparison-export`: 导出台新增预览播放/暂停按钮；导出范围适配交集逻辑；修复横屏视口下右栏子组件下溢、确保导出操作按钮完整可用。

## Impact

- **运行时契约**: `calculateUnifiedTimeline` 返回对象中将以交集区间作为主时间轴区间 `[intersectStart, intersectEnd]`，两端无重叠的单通道静止帧不再进入播放与导出序列。
- **组件变动**: `App.tsx`、`GeometryStep.tsx`、`AudioStep.tsx`、`Workbench.tsx`、`ExportPage.tsx` 以及核心几何与时间轴算法文件。
- **用户心智**: 打开对比台直接进入左右分区；时间轴总时长只涵盖两段视频均有动作的重叠区间；全流程顶栏可随时校正 BPM。
