# Spec Delta: timeline-audio-sync

## MODIFIED Requirements

### Requirement: 交互式音频波形与 60fps 平滑对拍锚点标注
系统 MUST 在音频标定界面以 60fps 帧率平滑驱动播放游标红线，波形图顶部呈现节拍刻度；底部控制栏移除 `< 1F`、`1F >`、`-20ms` 与 `+20ms` 按钮，锚点时间戳 MUST 支持用户点击后直接手动输入数字进行精确编辑；腾出横向空间后，右侧单一真实源 BPM 的 `+` 与 `-` 步进按钮与输入框在移动端横屏视口下 MUST 完整无截断展示。

#### Scenario: 结合慢放与微调精准锚定起拍帧
- **WHEN** 用户在音频对拍界面观察起手动作，定位起拍点并点击锚点时间输入框直接输入指定数值
- **THEN** 系统更新锚点时间戳，且点击「试听」时在锚点时刻发出一次高精度敲击脉冲音供声画验收

#### Scenario: 聚焦起拍锚定与无遮挡微调
- **WHEN** 用户在可用逻辑宽度 650px~850px 的横屏设备上打开音频对拍页面
- **THEN** 控制栏移除 1F 与 20ms 按钮，锚点支持数字直接修改，底部最右侧的 TAP 测速、BPM 加减按钮及输入框始终完整可见，不发生横向溢出或截断

### Requirement: 统一时间轴映射与双视频速率换算
系统 MUST 根据用户选定的对拍锚点和 BPM 对齐策略，计算各自相对速率比 $r_1, r_2$；统一时间轴有效范围 MUST 严格采用两路视频在锚点对齐后的「交集区间」（Intersection Interval），即 $start = \max(start_1, start_2)$ 且 $end = \min(end_1, end_2)$，严禁截取单边无画面的并集盲区；播放工作台提供的快捷复位按钮 SHALL 定位并起播至「锚点前 1 秒」（$\tau = -1.0s$，受交集起点截断保护）。

#### Scenario: 启用自选目标 BPM 对齐
- **WHEN** 视频 1 为 160 BPM，视频 2 为 150 BPM，用户选择统一对齐至 160 BPM
- **THEN** 系统计算视频 1 速率比为 1.0、视频 2 速率比为 160/150，在统一时间轴的有效交集区间内两者步调完全一致且两端无单边黑屏

#### Scenario: 快捷跳转至锚点前 1 秒播放
- **WHEN** 用户在播放工作台点击「锚点前 1s」快捷播放按钮
- **THEN** 系统将统一时间轴定位至 $\tau = -1.0s$ 并立即平滑启动双视频同步播放

### Requirement: 七档慢放与逐帧微调播放控制
系统 MUST 支持在播放工作台快速切换 `0.1 / 0.15 / 0.2 / 0.3 / 0.5 / 0.75 / 1.0` 七档播放倍速，移除 `< 1F` 与 `1F >` 按钮以简化触控操作链路。

#### Scenario: 切换为 0.1x 超慢放
- **WHEN** 用户在播放工作台选择 0.1x 倍速
- **THEN** 两路视频以各自相对速率比乘以 0.1 的速度超平滑同步慢放，底部控制栏精简无 1F 按钮
