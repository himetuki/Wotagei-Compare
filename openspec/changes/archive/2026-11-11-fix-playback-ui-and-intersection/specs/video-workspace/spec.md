# Spec Delta: video-workspace

## MODIFIED Requirements

### Requirement: 模式无缝切换与单项快速微调
系统 MUST 在顶部导航栏提供统一的全局步骤分段直达条，采用紧凑精炼的短标签命名（如 01 导入 / 02 空间1 / 03 空间2 / 04 对拍1 / 05 对拍2 / 06 对比台），确保在移动端横屏狭窄视口下严禁挤占导航空间；当双视频载入后允许用户在任意环节一键直达目标步骤微调参数，对比工作台初始默认进入左右分区模式，并支持无缝切换左右分区与半透明叠加模式。

#### Scenario: 快速微调单项参数
- **WHEN** 用户在对比工作台点击顶部步骤条中的「05 对拍2」
- **THEN** 系统直接切换至视频 2 音频对拍视图并展示既有参数，修改后点击顶部「06 对比台」或确认按钮即刻返回工作台

#### Scenario: 初始进入工作台默认左右分区
- **WHEN** 用户完成标定首次进入对比播放工作台
- **THEN** 系统默认以左右分区模式呈现双视频对比画面

### Requirement: 专业影视监视器极简暗黑视觉规范
系统全界面 MUST 采用纯黑与深炭灰底色、单一高对比主强调色、全矢量几何图标与等宽数字时间码，严禁在任何视图中渲染 Emoji 字符、无交互功能的装饰性文字（彻底移除 WC-MON 标识）；系统顶栏右侧在非对比台步骤中严禁残留或渲染黄色下一步按钮（仅对比台展示黄色导出片段按钮）；系统 MUST 在顶部导航栏常驻展示 CH1 与 CH2 的当前有效整数 BPM 徽章，且徽章在全流程中 MUST 支持用户点击后直接手动修改数值。

#### Scenario: 界面纯净度与图标检查
- **WHEN** 用户浏览导入页、空间标定页、音频对拍页、对比工作台及导出页
- **THEN** 界面仅呈现矢量图标、精炼控件标签与等宽时间码，左上角不显示 WC-MON，顶栏右侧不渲染被截断或多余的黄色操作按钮，且顶栏常驻可点击修改的 BPM 徽章

#### Scenario: 狭窄横屏视口零截断检查
- **WHEN** 用户在可用逻辑宽度仅 650px~850px 的横屏设备（含侧边金刚键）上浏览各视图
- **THEN** 顶栏 BPM 徽章、工作台「导出片段」按钮以及各视图底部操作面板均完整展示，不被挤出屏幕边缘，不发生截断

#### Scenario: 全流程任意位置点击顶栏修改 BPM
- **WHEN** 用户在对比工作台或向导任意步骤中点击顶栏右上角的「CH1 188 BPM」徽章
- **THEN** 系统激活手动数值输入，用户输入新数值并确认后，系统立即更新对应通道的基准 BPM 并同步重算所有关联时间轴与节拍刻度
