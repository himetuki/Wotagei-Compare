# Spec Delta

## MODIFIED Requirements

### Requirement: 独立导出工作台与 A-B 剪辑区间
系统 MUST 提供精简的独立导出工作台，直接沿用播放工作台当前已设定的对比模式、水平镜像、慢放倍率、声音源与视口状态，不在导出页重复堆砌上述参数的二次修改控件，仅专注支持用户在时间轴上设定起始时间点 A 与结束时间点 B（含「设当前为 A」「设当前为 B」「全片」快捷操作）及展示成片时长与总帧数摘要。

#### Scenario: 截取 8 秒核心招式导出
- **WHEN** 用户在导出工作台设置起点 A 与终点 B 相隔 8 秒并执行导出
- **THEN** 系统沿用播放工作台的参数仅针对这 8 秒时间区间进行逐帧离线合成，并在摘要中实时显示成片时长与总帧数

### Requirement: 所见即所得画布逐帧离线合成与实时单帧预览
系统在导出工作台中 MUST 提供实时的单帧画面预览，且离线导出时 MUST 严格复用播放工作台传入的三线正交对齐变换、水平镜像状态、透明度权重、视口位置与慢放倍速，按目标慢放倍速离线步进驱动逐帧渲染。

#### Scenario: 保持当前视口缩放与透明度导出
- **WHEN** 用户在播放工作台设定 0.2x 慢放后进入导出工作台并点击导出
- **THEN** 导出的 MP4 视频画面与工作台预览呈现完全一致的视野、透明度比例与 0.2x 慢放速度，无任何坐标或缩放偏离
