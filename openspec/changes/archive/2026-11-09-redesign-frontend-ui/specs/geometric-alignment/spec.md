# Spec Delta

## MODIFIED Requirements

### Requirement: 全量统一为三线正交锚定空间标定
系统 MUST 全量采用三线正交锚定模型（「两横一竖」或「两竖一横」二选一）作为唯一的空间标定体系，彻底移除矩形框类型字段与补标定分支，三线标定交互层 SHALL 精确贴合视频画幅显示区域且标尺角标文字不得发生非等比拉伸变形。

#### Scenario: 两横一竖模型标定
- **WHEN** 用户选择「两横一竖」模型并在视频画幅内拖拽两条横线分别贴合头顶与脚底/裆部、一条竖线对齐身体中轴
- **THEN** 系统记录两条横线归一化 Y 坐标与竖线归一化 X 坐标作为该视频的三线标定参数，且标尺线与标签清晰无变形

#### Scenario: 两竖一横模型标定
- **WHEN** 用户选择「两竖一横」模型并在视频画幅内拖拽两条竖线分别贴合左右脚外侧、一条横线贴合地面接触线
- **THEN** 系统记录两条竖线归一化 X 坐标与横线归一化 Y 坐标作为该视频的三线标定参数，且标尺线与标签清晰无变形
