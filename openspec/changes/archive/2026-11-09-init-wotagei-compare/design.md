# Design

## Context

本项目致力于为 WOTA 艺练习者打造一款能够在练习现场毫秒级同台对比自身动作与高手视频的 Android 优先跨平台工具。业务背景与动机参见 `proposal.md`。

移动端运行环境（特别是 Android 手机 WebView）存在视口面积有限、手势交互易误触、音视频解码能力差异等客观限制。系统必须在保证标定高精度（如站姿头顶、裆部、双脚与中轴线）的同时，保持播放帧同步、音频卡拍精准度，并实现预览与导出 100% 像素级一致。

## Goals / Non-Goals

**Goals:**
- 搭建基于 Vite + React + TypeScript + Capacitor 的纯前端技术架构，完成 Android 原生环境配置（强制横屏锁定与相册写入）。
- 实现「三线空间标定 → 音频锚点标定 → 对比播放与导出」的单视频全屏向导状态机，并在播放页支持单项快速微调与模式无缝切换。
- 全量统一为三线正交锚定模型（两横一竖 / 两竖一横），废除矩形框，实现左右分区与半透明叠加 100% 共用同一组三线标定参数。
- 左右分区采用中轴居中对称、地面沉底对齐，原视频全画幅完整呈现不截断，上方留出 45%+ 辽阔视野包容挥棒大光弧。
- 实现 WebAudio PCM 解码分析、Tap BPM 连续点击测速、60fps rAF 平滑波形游标、绝对主时钟（Master Clock）+ PLL 锁相环追赶同步引擎、以及带敲击脉冲音的卡拍试听。
- 实现基于 A-B 自定义剪辑区间的独立所见即所得离线视频合成与 MP4 导出工作台。

**Non-Goals:**
- 不引入复杂的原生 C++ 音视频库，优先选用浏览器标准的 HTMLVideoElement、Canvas、WebAudio 与 MediaRecorder 管线。
- 不引入画面任意角度旋转自由度，避免移动端误触导致地平线歪斜。
- 不强制全量漫长并集导出，以自由 A-B 剪辑区间提供极速成片。
- 不做云端存储、网络账号系统或在线社区分享，纯单机离线运行。

## Decisions

### 1. 跨平台技术底座与单画布渲染架构
- **决策链接**：[`docs/decisions/AgDR-0001-跨平台技术底座与单画布架构.md`](../../docs/decisions/AgDR-0001-跨平台技术底座与单画布架构.md)
- **技术要点**：
  - 选用 React + TS + HTML5 Canvas + WebAudio 配合 Capacitor 封装 Android 原生壳。
  - 核心设计在于让**实时预览画面**与**离线视频导出** 100% 共用同一个纯函数渲染器 `renderComparisonFrame(ctx, state)`。
  - 状态中仅包含模式、镜像、几何矩阵、时间戳与透明度权重，从而在根本上杜绝“预览是一套坐标、导出是另一套滤镜”造成的对齐偏差。

### 2. 线性对齐向导与三线正交锚定几何模型
- **决策链接**：[`docs/decisions/AgDR-0002-线性对齐向导与三线正交几何变换.md`](../../docs/decisions/AgDR-0002-线性对齐向导与三线正交几何变换.md)
- **技术要点**：
  - 采用“先图像后音频、先一后二”的线性向导，每个向导步骤单视频占满横屏全屏，最大化手势拖拽的标定精度。
  - 提供两种三线正交模型（两横一竖 / 两竖一横）。
  - 相对透明度 $p \in [-1, 1]$ 采用等亮线性混合（视频 1 权重 $\frac{1-p}{2}$，视频 2 权重 $\frac{1+p}{2}$），确保 $p=0$ 时画面亮度不衰减。

### 3. 双视频统一时间轴映射与合成节拍器策略
- **决策链接**：[`docs/decisions/AgDR-0003-双视频BPM时间轴映射与音频导出策略.md`](../../docs/decisions/AgDR-0003-双视频BPM时间轴映射与音频导出策略.md)
- **技术要点**：
  - 统一时间轴以两视频对拍锚点时刻作为 $\tau = 0$ 原点。
  - 自选 BPM 对齐时换算相对速率比 $r_i = \frac{\text{BPM}_{\text{target}}}{\text{BPM}_i}$，视频源时间戳 $t_i(\tau) = t_{i,0} + \tau \cdot r_i$。
  - 慢放下默认使用 WebAudio 锁相合成脉冲节拍器，0.1x 下声音依然清脆卡拍；同时支持切换单侧原视频音轨且全程保持变速不变调、不自动静音。

### 4. 左右分区视口对齐、Tap BPM 与独立 A-B 区间导出
- **决策链接**：[`docs/decisions/AgDR-0004-左右分区视口对齐、TapBPM与独立AB区间导出.md`](../../docs/decisions/AgDR-0004-左右分区视口对齐、TapBPM与独立AB区间导出.md)
- **技术要点**：
  - 增加 Tap BPM 连续点击屏幕测速算法与滑动平均滤波。
  - 开辟独立的导出配置全屏工作台，支持时间轴 A-B 自由剪辑、背景音乐与慢放倍速自选。

### 5. 全面废除矩形框并统一为三线正交锚定
- **决策链接**：[`docs/decisions/AgDR-0005-全面废除矩形框并统一为三线正交锚定.md`](../../docs/decisions/AgDR-0005-全面废除矩形框并统一为三线正交锚定.md)
- **技术要点**：
  - 废除矩形框体系与多余的微调滑块，左右分区与半透明叠加全量收敛为三线正交锚定模型。
  - 左右分区采用中轴对称、地面沉底对齐，原视频全画幅完整呈现不截断，上方留出 45%+ 辽阔视野包容挥棒大光弧。
  - 模式切换 0 成本免重标定，支持单项快速微调。

## Risks / Trade-offs

- **[Risk 1: 双视频硬件解码启动延迟导致音画脱节]** → 采用绝对主时钟（Master Clock）机制，以发声视频硬件时间戳作为全局时间基准（声画绝对零延迟），从属视频采用 PLL 锁相环 5% 速度微调平滑追赶，杜绝反复 seek 卡顿。
- **[Risk 2: 0.1x 慢放视频导出耗时过长]** → 提供 A-B 自定义片段剪辑，截取 5~10 秒核心招式片段离线逐帧步进导出，成片速度提升数十倍；同时提供实时进度与即时取消机制。

## Migration Plan

本项目为全新初始化工程，采用增量分步实施（架构底座 → 核心纯算法层 → 向导 UI 与工作台 → 导出管线与 Android 原生集成），不涉及任何存量数据与旧代码迁移。
