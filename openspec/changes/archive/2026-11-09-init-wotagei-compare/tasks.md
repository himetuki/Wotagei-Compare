## 2. 核心数学与音频渲染算法实现

- [x] 2.1 实现三线正交（两横一竖 / 两竖一横）缩放比与锚点平移计算算法及左右分区三线中轴对称与地面沉底投影算法，编写独立执行脚本验证输入测试点后的几何变换矩阵计算输出
- [x] 2.2 实现基于 WebAudio PCM 数据的音频能量包络、自相关 BPM 自动测算算法与 TapTempoTracker 连续点击测速类，验证能对典型音频样本计算出准确的整数 BPM
- [x] 2.3 实现双视频统一相对时间轴映射函数（处理速率比与时间戳换算）及两视频并集时间区间计算函数，验证时间映射和区间边界边界测试用例
- [x] 2.4 实现单画布纯函数渲染器 `renderComparisonFrame(ctx, state)`，支持左右分区三线投影与半透明叠加、独立水平镜像翻转、等亮线性相对透明度混合（$p \in [-1, 1]$）及视口缩放平移，验证 Canvas 离屏绘制无像素畸变

## 3. 线性全屏标定向导组件开发

- [x] 3.1 实现双路本地视频导入组件与对比模式初始选择视图，持久化保存视频引用与状态，验证文件载入后能正确提取时长与画面尺寸且切换模式不掉视频
- [x] 3.2 实现单视频全屏图像标定组件，支持找帧控制、独立水平镜像开关，全量统一为三线正交（两横一竖 / 两竖一横）游标拖动调整，验证标定坐标能实时同步至状态机
- [x] 3.3 实现单视频全屏音频标定组件，展示交互式波形图（60fps rAF 平滑游标，精致顶部刻度消除横条纹）、BPM 显示与手动编辑框、Tap BPM 连续点击测速按钮、起拍帧定位与对拍锚点打点按钮、以及带卡拍敲击音的试听功能，验证设定的锚点时间戳与 BPM 记录正确
- [x] 3.4 串联「视频1三线 → 视频2三线 → 视频1音频 → 视频2音频与BPM策略」的线性状态机，支持上一步回退保留参数与单项快速微调，验证能够连贯走完完整标定流程

## 4. 同台对比播放工作台开发

- [x] 4.1 实现播放工作台主布局，引入绝对主时钟（Master Clock）+ 从属视频 PLL 锁相环 5% 微调追赶同步引擎，杜绝频繁 seek 造成的卡顿黑屏与声画延迟，验证双视频在暂停、跳转时画面严格同步
- [x] 4.2 实现 `0.1 / 0.15 / 0.2 / 0.3 / 0.5 / 0.75 / 1.0` 七档慢放切换及暂停时的上一帧/下一帧逐帧步进功能，验证在 0.1x 慢放下画面播放平滑且逐帧步进精准
- [x] 4.3 实现播放页半透明叠加视口单指拖拽平移、双指捏合缩放手势交互以及相对透明度滑块调节，验证 $p=0$ 视角下画面亮度稳定不发暗
- [x] 4.4 实现基于 WebAudio 的高精度脉冲节拍器合成器（与对拍锚点相位严格锁相，超慢放不失真）以及单侧原视频音轨切换（开启变速不变调且不自动静音），验证切换声音源后发声符合预期
- [x] 4.5 左右分区与半透明叠加共享三线正交参数，实现模式 0 成本自由切换，并在顶部提供单项快速微调入口，验证无需二次补标定即可无缝切换
