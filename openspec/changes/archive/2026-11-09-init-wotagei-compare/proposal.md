# Proposal

## Why

WOTA 艺（御宅艺）练习者在进阶扒技过程中，难以在练习现场将自己的练习视频与高手参考视频进行毫秒级同台对比与慢放分析。以往必须依赖回家后繁琐的后期剪辑，迭代反馈周期过长，稍纵即逝的身体动作感悟极易消散。

本项目旨在构建一款 Android 优先的跨平台移动端工具（基于 React + TypeScript + Canvas/WebAudio + Capacitor 原生壳），通过强制横屏下的单视频全屏线性向导，提供统一的三线正交空间锚定、自动与 Tap BPM 交互测速、毫秒级对拍打点与试听、绝对主时钟（Master Clock）+ PLL 锁相环同步引擎、0.1x~1.0x 超慢放结合精准合成节拍器，以及独立 A-B 剪辑区间所见即所得 MP4 导出，让练习者在现场即可实时对照纠错，大幅提升扒技迭代效率。

## What Changes

本变更是项目的初始化创建（首个 Propose），从零建立完整的系统能力与核心技术底座：

- **技术底座与工程骨架**：建立基于 Vite + React + TypeScript 的纯前端架构，配置 Capacitor Android 原生封装、全程强制横屏锁定与系统相册存储权限。
- **全屏线性标定向导与单项微调**：建立「选择模式 → 视频 1 三线标定 → 视频 2 三线标定 → 视频 1 音频标定 → 视频 2 音频与 BPM 策略 → 播放工作台」线性流转状态机，并在工作台提供单项快速微调入口，已导入视频与设置永久保留。
- **全量统一的三线正交空间几何对齐**：
  - 左右两路视频均支持独立的水平镜像翻转开关。
  - 全面废除矩形框，统一收敛为「两横一竖」（头顶/脚底/中轴）与「两竖一横」（双脚/地面）三线正交锚定模型。
  - 左右分区模式：将人体中轴线居中对齐至半区中央、脚底地面沉底对齐，原视频全画幅完整呈现不截断，上方空出 45%+ 辽阔视野完整容纳挥棒大光弧。
  - 半透明叠加模式：依据三线参数计算等比缩放与平移对齐，不引入任何旋转；支持视口手势平移缩放以及 $[-1, 1]$ 等亮线性相对透明度调节。
- **统一时间轴、Tap BPM 与声画同步引擎**：
  - 音频加载后自动测算初始 BPM，并提供「Tap BPM 连续点击测速」交互；支持波形图 60fps 平滑追踪与带敲击脉冲音的「试听卡拍」。
  - 支持「不对齐 BPM」与「自选 BPM 对齐（按视频 1 / 按视频 2 / 手动指定目标值）」，建立统一时间轴映射。
  - 播放时采用发出声音的视频作为绝对主时钟（Master Clock），从属视频采用 PLL 锁相环 5% 微调平滑追赶，杜绝频繁 seek 与卡顿脱节，声画绝对零延迟。
  - 提供 `0.1 / 0.15 / 0.2 / 0.3 / 0.5 / 0.75 / 1.0` 七档慢放与逐帧微调。
  - 默认以 WebAudio 合成清脆节拍器，亦支持切换单侧原视频音轨（全程变速不变调且不自动静音）。
- **所见即所得 A-B 剪辑视频导出工作台**：
  - 开辟独立的导出配置界面，支持自由设定起点 A 与终点 B 截取核心招式片段，避免漫长全量导出。
  - 支持自选背景音乐/节拍器、慢放倍速与透明度，提供实时单帧预览与进度反馈，离线合成 MP4 并保存至相册或直接下载。

## Capabilities

### New Capabilities

- `video-workspace`: 负责跨平台移动端底座、全程强制横屏、双视频导入与状态持久化、线性向导流转、单项快速微调及播放工作台整体布局交互。
- `geometric-alignment`: 负责独立水平镜像翻转、全量统一的三线正交锚定模型（两横一竖 / 两竖一横）、左右分区中轴与地面对齐全画幅投影、叠加并集画幅手势缩放平移以及 $[-1, 1]$ 等亮线性相对透明度混合。
- `timeline-audio-sync`: 负责音频波形提取、Tap BPM 连续点击测速、60fps rAF 平滑时钟跟踪、带敲击脉冲音的卡拍试听、绝对主时钟（Master Clock）+ PLL 锁相环同步引擎、七档超慢放、以及 WebAudio 合成节拍器与单侧原声音频管理。
- `comparison-export`: 负责独立导出工作台、A-B 自定义剪辑区间计算、实时单帧画面预览、离线逐帧 Canvas 复用渲染、音频混流、MP4 视频编码与相册保存。

### Modified Capabilities

（无，本项目为全新初始化项目，尚无存量 Capability）

## Impact

- **新增代码与架构**：
  - `src/types/`：定义几何标定、时间轴、向导流转与音视频播放导出的核心契约接口。
  - `src/core/`：实现纯函数形式的几何变换算法、Tap BPM 与音频分析算法、时间轴映射算法、Canvas 合成渲染与 MP4 导出管线。
  - `src/components/`：实现线性向导步骤视图、波形图与交互游标组件、同台对比播放工作台及独立导出全屏工作台。
  - `android/`：Capacitor 生成并配置的 Android 原生工程（包含横屏配置与存储权限声明）。
- **外部依赖**：引入 React、TypeScript、Vite、Capacitor (@capacitor/core, @capacitor/android, @capacitor/screen-orientation, @capacitor/filesystem) 以及相关音视频处理依赖。
- **向后兼容**：全新项目，不涉及存量代码迁移或向后兼容负担。
