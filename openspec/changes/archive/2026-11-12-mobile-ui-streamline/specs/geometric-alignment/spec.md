# Spec Delta

## MODIFIED Requirements

### Requirement: 独立视频水平镜像翻转
系统 MUST 为 CH1 和 CH2 提供完全独立的水平镜像翻转开关，开启后该路视频在向导标定界面、对比播放视口及最终导出画面中 SHALL 保持水平镜像状态；空间标定界面与播放工作台中的镜像翻转按钮均 MUST 采用标准的左右水平镜像矢量图标（两侧三角形与垂直对称中轴），严禁渲染垂直上下对顶的错误图标。

#### Scenario: 开启单侧视频镜像
- **WHEN** 用户在空间标定界面或播放工作台查看或点击镜像翻转按钮
- **THEN** 图标呈现符合人体工程学预期的水平左右翻转形状，该通道画面水平翻转，另一通道保持原向不变

### Requirement: 全量统一为三线正交锚定空间标定
系统 MUST 全量采用三线正交锚定模型（「两横一竖」或「两竖一横」二选一）作为唯一的空间标定体系；空间标定页面彻底移除原上方第二行工具栏，将画面区域纵向放大填满上下空间；标定模型选择升级为下拉菜单并迁移至顶栏右上角，文案为「两横一竖」与「两竖一横」；镜像开关亦迁移至顶栏右上角；三线标定角标文字 SHALL 仅显示纯文本角色标签并移除百分比数值；两横一竖模型下，头顶黄线角标 MUST 置于黄线左下方，脚底绿线角标 MUST 置于绿线右上方以避免底部进度条遮挡；空间标定底部控制栏仅保留播放/暂停与时间轴滑块，移除 `< 1F` 与 `1F >` 步进按钮。

#### Scenario: 两横一竖模型标定
- **WHEN** 用户在顶栏下拉菜单中选择「两横一竖」模型并在视频画幅内拖拽两条横线贴合头顶与脚底、一条竖线对齐身体中轴
- **THEN** 系统记录两条横线与竖线坐标，头顶标签显示于黄线左下方，脚底标签显示于绿线右上方，角标不显示百分比数值，画面纵向填满顶部导航栏与底部控制栏之间的全部可用视口

#### Scenario: 两竖一横模型标定
- **WHEN** 用户在顶栏下拉菜单中选择「两竖一横」模型并在视频画幅内拖拽两条竖线分别贴合左右脚外侧、一条横线贴合地面接触线
- **THEN** 系统记录两条竖线归一化 X 坐标与横线归一化 Y 坐标，标尺角标仅显示中文角色名称不显示百分比

#### Scenario: 空间标定控制栏精简
- **WHEN** 用户处于视频空间标定页面
- **THEN** 界面不显示上方第二行工具栏，视频画幅放大填满上下视口，底部控制栏不显示 1F 逐帧微调按钮，仅提供播放/暂停与时间轴拖动定位
