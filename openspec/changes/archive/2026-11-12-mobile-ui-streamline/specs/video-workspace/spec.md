# Spec Delta

## MODIFIED Requirements

### Requirement: 双路本地视频文件导入与状态持久驻留
系统 MUST 支持用户在导入步骤中分别选择并载入两个本地视频文件并展示分辨率、时长与检测 BPM，导入页不设初始对比模式切换或演示样本生成按钮；双通道槽位统一标记为「CH1」与「CH2」，严禁使用「基准源」「对比源」等定性称谓；只要用户不主动更换视频，其几何与音频参数 SHALL 永久保留在内存中，在任意步骤间跳转时严禁丢失已导入的视频。

#### Scenario: 首页切换模式保留视频
- **WHEN** 用户导入两个视频并进入后续标定或对比工作台后，再次切回导入步骤查看
- **THEN** 系统完整保留两个视频的引用、几何标定与音频参数，不发生视频丢失或重置，且槽位仅标识为 CH1 与 CH2，无基准源/对比源文案

### Requirement: 线性全屏向导状态流转
系统 MUST 支持按「导入 → CH1 空间标定 → CH2 空间标定 → CH1 对拍标定 → CH2 对拍标定 → 对比台 → 导出片段」的顺序推进全屏标定与对比导出，过程中单视频 SHALL 占满横屏主视口以保证最高标定精度。

#### Scenario: 依序完成向导进入播放工作台
- **WHEN** 用户完成双路视频导入、两视频的三线空间标定以及两视频的音频对拍锚点设定
- **THEN** 系统进入同台对比播放工作台并加载双方对齐参数

### Requirement: 模式无缝切换与单项快速微调
系统 MUST 在顶部导航栏提供统一的全局步骤分段直达条，彻底移除所有数字标号（`01`~`06`），采用纯精炼短标签命名（`导入` / `CH1空间` / `CH2空间` / `CH1对拍` / `CH2对拍` / `对比台` / `导出片段`），确保在移动端横屏狭窄视口下严禁挤占导航空间；当双视频载入后允许用户在任意环节一键直达目标步骤微调参数，对比工作台初始默认进入左右分区模式，并支持无缝切换左右分区与半透明叠加模式。

#### Scenario: 快速微调单项参数
- **WHEN** 用户在对比工作台点击顶部步骤条中的「CH2对拍」
- **THEN** 系统直接切换至 CH2 音频对拍视图并展示既有参数，修改后点击顶部「对比台」或确认按钮即刻返回工作台

#### Scenario: 初始进入工作台默认左右分区
- **WHEN** 用户完成标定首次进入对比播放工作台
- **THEN** 系统默认以左右分区模式呈现双视频对比画面

### Requirement: 专业影视监视器极简暗黑视觉规范
系统全界面 MUST 采用纯黑与深炭灰底色、单一高对比主强调色、全矢量几何图标与等宽数字时间码，严禁在任何视图中渲染 Emoji 字符、无交互功能的装饰性文字（彻底移除 WC-MON 标识）；系统顶栏右侧在非对比台步骤中严禁残留或渲染黄色操作按钮；顶部导航栏右上角的 `CH1 …… BPM` 与 `CH2 …… BPM` 徽章仅在「对比台」步骤展示，在其他步骤（导入、空间、对拍）中彻底隐藏；在空间标定步骤中，顶栏右侧承载三线模型下拉菜单与镜像开关；全软件界面统一采用 `CH1` 与 `CH2`，彻底移除 `视频 1`、`视频一`、`CH 01`、`CH 02` 等冗余命名。

#### Scenario: 界面纯净度与图标检查
- **WHEN** 用户浏览导入页、空间标定页、音频对拍页、对比工作台及导出页
- **THEN** 界面仅呈现矢量图标、精炼控件标签与等宽时间码，左上角不显示 WC-MON，顶栏右侧在非对比台步骤不显示 BPM 徽章（对比台常驻显示且支持点击修改），全界面通道标识严格为 CH1 与 CH2

#### Scenario: 狭窄横屏视口零截断检查
- **WHEN** 用户在可用逻辑宽度仅 650px~850px 的横屏设备（含侧边金刚键）上浏览各视图
- **THEN** 无数字标号的顶栏步骤按钮、顶栏右侧控件以及各视图底部操作面板均完整展示，不被挤出屏幕边缘，不发生截断

#### Scenario: 全流程任意位置点击顶栏修改 BPM
- **WHEN** 用户在对比工作台中点击顶栏右上角的「CH1 188 BPM」徽章
- **THEN** 系统激活手动数值输入，用户输入新数值并确认后，系统立即更新对应通道的基准 BPM 并同步重算所有关联时间轴与节拍刻度（在非对比台步骤中顶栏不显示该徽章）
