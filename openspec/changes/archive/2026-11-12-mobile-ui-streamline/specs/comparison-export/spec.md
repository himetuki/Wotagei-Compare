# Spec Delta

## ADDED Requirements

### Requirement: 对比工作台可折叠工具栏与弹出式 BPM 对齐菜单
对比工作台的上方参数工具栏（对比模式、声音输出源、独立镜像）MUST 默认收起以最大化监看视口面积；当用户处于对比台步骤时，点击顶部导航栏的「对比台」选项卡 SHALL 触发工具栏的展开与收起切换；对比模式切换选项顺序 MUST 为「分区」在前、「叠加」在后，且初始默认选用「分区」模式；对比工作台底部控制栏右下角 MUST 提供可向上弹出的 BPM 对齐策略菜单（替代原静态 SYNC 徽章），支持「原速」「随 CH1」「随 CH2」「手动」切换及手动数值微调，并显示当前有效同步 BPM。

#### Scenario: 点击顶部对比台标签收放工具栏
- **WHEN** 用户处于对比台视图且工具栏处于默认收起状态，点击顶部导航栏的「对比台」标签
- **THEN** 上方参数工具栏平滑展开露出；再次点击「对比台」标签，工具栏重新收起，中央视频画布纵向空间即刻扩展

#### Scenario: 默认分区模式与顺序呈现
- **WHEN** 用户初次进入对比工作台
- **THEN** 系统默认以左右分区模式呈现，模式切换组第一项为「分区」、第二项为「叠加」

#### Scenario: 底部右下角向上展开修改 BPM 对齐策略
- **WHEN** 用户点击对比台右下角的 `SYNC …… BPM` 区域
- **THEN** 系统向上展开弹出策略菜单，列出「原速」「随 CH1」「随 CH2」「手动」，用户选择任一项后即刻更新时间轴换算速率并关闭菜单

## MODIFIED Requirements

### Requirement: 独立导出工作台与 A-B 剪辑区间
系统 MUST 提供独立的导出工作台并作为顶部全局导航栏中的「导出片段」步骤直达；时间轴 A-B 剪辑区间 MUST 统一在同一根有效重叠交集轴上进行单轴标定，标题文案更新为「导出区间」，彻底移除「全片」按钮；导出工作台右侧面板 MUST 进行移动端横屏视口自适应布局，子框体（起止截取、成片统计、导出进度与操作按钮）严禁超出主容器下端，底部的「开始渲染导出」按钮在任何设备上 MUST 100% 完整可见且触手可及。

#### Scenario: 截取 8 秒核心招式导出
- **WHEN** 用户在导出工作台同一根交集时间轴上设置起点 A 与终点 B 相隔 8 秒并执行导出
- **THEN** 系统沿用播放工作台的参数仅针对这 8 秒交集子区间进行逐帧离线合成，并在摘要中实时显示成片时长与总帧数，标题显示「导出区间」且无「全片」按钮

#### Scenario: 移动端横屏下右侧面板零溢出检查
- **WHEN** 用户在可用逻辑高度 360px~450px 的移动设备横屏浏览导出工作台
- **THEN** 右侧面板内所有子卡片紧凑排布无截断，且底部的「开始渲染导出」按钮完全展示在视口内，可直接点击触发离线渲染

### Requirement: 所见即所得画布逐帧离线合成与实时单帧预览
系统在导出工作台中 MUST 提供画布预览，并在预览栏内提供「预览 / 暂停」控制按钮，复用对比工作台的双视频音画硬件时间戳同步驱动引擎，允许用户连续平滑播放预览当前导出区间内的同台合成效果；离线导出时 MUST 严格复用对比工作台的几何与时间轴变换参数。

#### Scenario: 保持当前视口缩放与透明度导出
- **WHEN** 用户在播放工作台设定 0.2x 慢放后进入导出工作台并点击导出
- **THEN** 导出的 MP4 视频画面与工作台预览呈现完全一致的视野、透明度比例与 0.2x 慢放速度，无任何坐标或缩放偏离

#### Scenario: 导出台内连续播放预览
- **WHEN** 用户在导出工作台点击画布下方的「预览」按钮
- **THEN** 系统启动双视频同步播放管线，预览画布按当前设定倍速平滑连续呈现双视频合成画面，预览滑块随之实时平滑推进，按钮文案更新为「暂停」；再次点击后暂停播放
