# Design

## Context

在移动端横屏环境下（可用逻辑高度仅 360px~450px），WOTA 艺同台对比慢放软件的核心视口是视频画面本身。当前应用在向导各步骤与对比工作台中存在双行顶栏（主步骤栏 + 子工具栏）、BPM 与锚点时间信息重复镜像展示、BPM 对齐策略过早放置在单视频对拍步骤、工作台工具栏未折叠常驻占高、以及导出台预览因缺乏音视频同步管线而卡顿黑屏等问题。

设计目标是在完全保留现有空间标定、时间轴对齐与离线导出全部功能的前提下，通过层级精简、插槽迁移、单一真实源收敛与单轴标定，实现真正的大画面沉浸式移动端监看体验。

详细决策见架构决策记录：[AgDR-0010](../../docs/decisions/AgDR-0010-移动端全屏视口层级精简与单轴导出交互重构.md)。

## Goals / Non-Goals

**Goals:**
- **消除视口挤压**：彻底移除向导（空间标定与音频对拍）中的第二行工具栏，释放至少 40px 纵向高度，让视频画幅在上下视口之间自适应填满。
- **单一真实源**：全流程消除相同信息的重复渲染（顶栏 BPM 仅在对比台呈现，移除对拍顶栏锚点时间），各步骤仅保留唯一的交互与编辑入口。
- **决策链路合理化**：将 BPM 对齐策略从单视频对拍迁移至对比工作台右下角，改造为向上弹出的策略选择菜单。
- **对比台视口最大化**：对比工作台上方的模式/音轨/镜像工具栏默认折叠收起，点击顶部「对比台」选项卡可自由切换收展；对比模式调换为「分区」在前且为默认模式。
- **导出单轴化与可靠预览**：导出片段升级为顶部直达步骤；A-B 起止时间合并为单根交集时间轴标定，移除「全片」按键；导出页预览复用对比台的双视频同步播放循环，确保点击「预览」流畅发声与画面连续渲染。
- **统一术语体系**：移除顶部导航栏所有数字前缀（`01`~`06`）；全软件全量统一使用 `CH1` 与 `CH2`，彻底废除 `视频 1`、`CH 01`、`基准源`、`对比源` 等不一致称谓。

**Non-Goals:**
- 不重构底层 WebCodecs / MediaRecorder 离线导出内核及 WebAudio 合成节拍器算法。
- 不引入第三方大型 UI 组件库（如 Material UI / Ant Design），全部采用轻量级原生 HTML5 / CSS 与 Lucide 矢量图标构建。
- 不在代码中保留向后兼容逻辑。

## Decisions

### 1. 顶栏动态插槽与数字编号清除

- **步骤定义精简**：
  更新 `WIZARD_STEPS` 为纯语义化短标签：
  - `import`: `导入`
  - `geometry-video1`: `CH1空间`
  - `geometry-video2`: `CH2空间`
  - `audio-video1`: `CH1对拍`
  - `audio-video2`: `CH2对拍`
  - `workbench`: `对比台`
  - `export`: `导出片段`
- **顶栏右侧上下文动态插槽**：
  - 当 `step === 'workbench'`：渲染 `CH1 ... BPM` 与 `CH2 ... BPM` 可编辑徽章；
  - 当 `step === 'geometry-video1'` 或 `'geometry-video2'`：渲染当前通道的模型切换下拉菜单（`两横一竖` / `两竖一横`）与独立镜像开关（配带标准水平左右翻转矢量图标）；
  - 当处于其他步骤（`import`、`audio-video1`、`audio-video2`、`export`）：右侧不显示冗余徽章或控制项。

### 2. 空间标定与音频对拍第二栏删除与满高渲染

- 在 `GeometryStep.tsx` 与 `AudioStep.tsx` 中直接删除 `.toolbar-row` 结构；
- 空间标定中的视频内接计算 `fitScale = Math.min(stageSize.width / vW, stageSize.height / vH)` 自动由于舞台可用高度增加 40px 而等比放大；
- 音频对拍中移除顶栏锚点展示，移除 05 步骤中的 BPM 对齐控制项，中间 `<video>` 自适应放大，底部控制栏保持紧凑布局。

### 3. 对比工作台折叠工具栏与底栏 BPM 弹出菜单

- **工具栏折叠机制**：
  - 在应用层维护 `isWorkbenchToolbarExpanded`（默认 `false`）；
  - 当用户处于 `workbench` 步骤时，点击顶部导航栏中的 `对比台` 选项卡，触发展开/收起切换；
  - 折叠时工具栏不占用 DOM 高度，对比画布获得最大纵向视口。
- **模式排序与默认值**：
  - 模式切换按钮顺序调整为 `[ 分区 | 叠加 ]`，初始默认状态设为 `split-screen`。
- **右下角 BPM 对齐弹出菜单**：
  - 替换原静态 `SYNC ... BPM` 徽章为一个互动触发按钮；
  - 点击后向上展开 Popover 浮层，包含：
    - 策略选择：`原速`、`随 CH1 (bpm1)`、`随 CH2 (bpm2)`、`手动`；
    - 当选择 `手动` 时展开数字输入框输入目标自定义 BPM；
  - 浮层外部点击或选择后自动关闭，实时触发 `calculateUnifiedTimeline` 重算。

### 4. 导出台单轴标定与音画同步预览引擎复用

- **单轴导出区间**：
  - 标题调整为「导出区间」，彻底移除「全片」按键；
  - 在同一根交集时间轴刻度（`intersectInterval.start` 至 `intersectInterval.end`）上整合 IN（A）与 OUT（B）区间，同时保留当前游标快速赋值按键「设当前为 A」「设当前为 B」及高精度数值展示；
- **同步预览循环驱动**：
  - 复用 `Workbench` 中的主时钟与双视频播放驱动逻辑：点击「预览」时调用 `v1.play()` 与 `v2.play()`，并在 `requestAnimationFrame` 循环中驱动 `renderComparisonFrame(ctx, v1, v2, ...)`，时间达到 `clipEnd` 时自动环回至 `clipStart`；
  - 按钮文案设为「预览 / 暂停」，彻底消除单纯更新 `currentTime` 造成的单帧卡顿与无画面问题。

### 5. 术语体系全面收敛

- `ImportStep.tsx`：槽位卡片统一显示为 `CH1` 与 `CH2`，移除「基准源」「对比源」；
- 全局代码与界面全量替换：
  - `视频 1`、`视频一`、`CH 01` → `CH1`
  - `视频 2`、`视频二`、`CH 02` → `CH2`

## Risks / Trade-offs

- **[Risk]** 对比台上方工具栏默认收起可能导致新用户不知道如何切换为半透明叠加模式或调整镜像。
  - **Mitigation**: 点击「对比台」选项卡本身即可切换折叠；在对比台画面右上角亦可保留极简的小型浮动展开箭头指示或在首次加载时给出提示。
- **[Risk]** 顶部导航栏增加到 7 个短标签，在极窄屏幕设备上可能受到宽度限制。
  - **Mitigation**: 移除了原有的 `01` `02` 编号后，每个步骤仅 3~4 个中文字符，总字符数由原先的 38 字符大幅压缩至 24 字符，总宽度缩减约 30%，在 650px 以上横屏设备中均可舒展排列且保持安全区避让。
- **[Risk]** 导出预览复用 HTML5 播放管线时，若两视频解码器起播延迟不同可能产生微小相位差。
  - **Mitigation**: 沿用对比台成熟的相对速率换算与时间戳校准逻辑，起播前统一精准 `currentTime` 预寻道后再统一触发 `play()`。
