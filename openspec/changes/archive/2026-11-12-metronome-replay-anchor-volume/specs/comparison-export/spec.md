# Spec Delta

## MODIFIED Requirements

### Requirement: 所见即所得画布逐帧离线合成与实时单帧预览
系统在导出工作台中 MUST 提供画布预览，并在预览栏内提供「预览 / 暂停」控制按钮，复用对比工作台的双视频音画硬件时间戳同步驱动引擎；在预览播放期间，系统 MUST 依据所选声音源（CH1 原声、CH2 原声、合成节拍器或静音）实时发声并支持变速不变调；当预览播放到达 A-B 截取区间终点时，系统 MUST 自动循环重放至起点，且声音源为合成节拍器时节拍器 MUST 无缝重放并持续发声，严禁发生第二轮及后续循环失音；在预览中拖拽进度条定位或起播时，节拍器重拍 MUST 严格与统一时间轴锚点 $\tau = 0$ 保持锁相；当用户在暂停或播放状态下拖拽进度条、或拖动后立即触发播放时，系统 MUST 具备寻道互斥与起播就绪防抖机制，严禁在视频处于寻道未就绪状态（`seeking` 或 `readyState < 2`）时进行高频重复硬赋值（Seek Thrashing）；系统 MUST 实现从属通道防雪崩锁相环追赶控制，且在播放状态下拖动时间进度条 SHALL 重新定位至目标时刻并保持双侧平滑推进播放，严禁触发单侧画面卡死或自动暂停；离线导出时 MUST 严格复用对比工作台的几何与时间轴变换参数。

#### Scenario: 保持当前视口缩放与透明度导出
- **WHEN** 用户在播放工作台设定 0.2x 慢放后进入导出工作台并点击导出
- **THEN** 导出的 MP4 视频画面与工作台预览呈现完全一致的视野、透明度比例与 0.2x 慢放速度，无任何坐标或缩放偏离

#### Scenario: 导出台内连续播放预览
- **WHEN** 用户在导出工作台以合成节拍器为声音源点击画布下方的「预览」按钮并在播放中点击或拖动时间进度条，或画面播放推进至区间终点自动循环重放
- **THEN** 系统按当前设定倍速平滑连续呈现双视频合成画面并输出高响度节拍器声音，跳转到目标时刻后画面与声音不中断、继续平滑推进播放，循环重放后节拍器无缝继续敲击发声，按钮保持为「暂停」状态

#### Scenario: 拖动进度条后立即播放双侧流畅无卡顿
- **WHEN** 用户在导出工作台拖动预览时间进度条至任一交集时刻，并在 100ms 内快速点击「预览」开始播放
- **THEN** 系统等待双视频均完成寻道并进入可渲染就绪状态后同步启动时钟与画面渲染，双侧视频均平稳起播，不存在任一单侧画面冻结、疯狂重寻道掉帧或剧烈顿挫现象

#### Scenario: 播放中连续高频拖动进度条防雪崩
- **WHEN** 导出工作台处于预览播放状态，用户连续高频滑动时间滑块或快速点击定位
- **THEN** 系统对寻道请求进行节流保护，不向处于寻道中的视频重复推送新时刻，寻道完成后立即恢复平滑同步，双通道视频保持同频播放与音画对齐

### Requirement: 同步音频混流与 MP4 编码
系统 MUST 将用户选定的声音配置（合成节拍器、视频 1 原声、视频 2 原声或静音）离线渲染为音频流，与离线渲染的视频帧通过基于确定性时间戳（PTS）的 WebCodecs 或等效离线封包管线合成为标准的 MP4 容器文件；当声音源为合成节拍器时，离线音频合成算法 MUST 严格以 $\tau = 0$ 对应导出时间点锁定小节第 1 拍重拍（$k \equiv 0 \pmod 4$），采用绝对拍号整数步进消除浮点累加误差，且在波形能量与音色响度包络上与实时节拍器保持完全一致，达到匹敌 -5.9 LUFS 级别伴奏的充沛响度；导出的成片物理播放总时长 MUST 精确等于截取区间除以慢放倍率（即 `(clipEnd - clipStart) / slowMotionRate`），严禁受离线渲染过程消耗的物理挂钟时间影响；视频与音轨在整个导出成片中 MUST 保持严格的毫秒级声画同步与同等播放时长。

#### Scenario: 导出携带合成节拍器声音
- **WHEN** 当前声音源为合成节拍器并执行视频导出
- **THEN** 生成的 MP4 文件包含与画面动作精准对齐的高响度节拍器音频轨，在外部播放器播放时声画完全同步，且对齐锚点 $\tau = 0$ 处精准响起小节重拍，整段音频音量充足、清脆不爆音

#### Scenario: 慢放导出成片时长与物理挂钟解耦
- **WHEN** 用户在导出工作台截取 3 秒的交集区间并设定 0.25x 慢放执行导出
- **THEN** 无论离线逐帧渲染在物理设备上实际消耗了多长时间，最终导出的 MP4 视频时长严格等于 12 秒（3 / 0.25 秒），且全片以均匀设定的帧率流畅播放，画面动作不发生因寻道等待导致的卡顿拉长

#### Scenario: 导出携带单侧视频原声音轨
- **WHEN** 用户选择 CH1 原声或 CH2 原声作为导出声音源并执行导出
- **THEN** 系统离线提取对应通道在截取区间内的音频采样数据，按统一时间轴速率比与慢放倍率变速混音并写入导出的 MP4 文件，外部播放器播放时包含正常清晰的伴奏声音，声画完全对齐
