# Spec Delta

## MODIFIED Requirements

### Requirement: 锁相合成节拍器音频驱动
系统 MUST 默认提供由 WebAudio 生成的高穿透力脉冲节拍器；节拍器相位 MUST 严格以统一时间轴对拍锚点 $\tau = 0$ 为基准原点，定义拍点周期 $\Delta\tau = 60 / effectiveBpm$ 与拍号 $k = \mathrm{round}(\tau / \Delta\tau)$，并保证所有满足 $k \equiv 0 \pmod 4$ 的拍点均为小节第 1 拍重拍（Downbeat / 强拍，频段为 1500Hz/800Hz 复合脉冲），其余非零模数为弱拍（800Hz 干净脉冲）；节拍器 MUST 具备时间回退与循环自愈机制，当播放器到达终点循环重放、向后寻道（Seek）或时间戳发生逆流时，系统 MUST 自动重置拍点基准，严禁在重放后发生节拍器哑火静音；在 $\tau = 0$ 或任意拍点附近起播时，系统 MUST 引入起播容差判定，精确触发当前重拍，严禁起播吞音；音频合成管线 MUST 采用包含高次谐波的冲击波形并接入动态范围压缩器（DynamicsCompressor），有效脉冲时长延长至 50~60ms，使其感知响度与穿透力能够匹敌 -5.9 LUFS / -8.8 dB RMS 级别的高响度 WOTA 艺伴奏视频，在 0.1x~1.0x 全档位慢放与外放扬声器下保持清脆饱满且绝不破音削顶。

#### Scenario: 播放时节拍器精准敲击
- **WHEN** 播放工作台处于播放状态且声音源选为“节拍器”
- **THEN** WebAudio 在每个节拍时刻精准发出敲击音，节拍节奏与画面动作卡点完全同步

#### Scenario: 视频到达终点循环重放节拍器持续发声
- **WHEN** 对比工作台或导出工作台预览播放推进到交集或截取区间终点并自动回绕重放至起点
- **THEN** 系统重置节拍计数器，节拍器在新的一轮循环播放中无缝继续发声，严禁发生第二轮及后续循环失音或静音

#### Scenario: 锚点起播与重拍严格卡点
- **WHEN** 用户将时间轴定位至对齐锚点 $\tau = 0$ 处点击播放，或视频播放自然流转跨越 $\tau = 0$
- **THEN** 系统在 $\tau = 0$ 对应的时间戳发出明亮的 1500Hz/800Hz 强拍敲击音，起播第一声即为重拍，严禁吞掉锚点强拍或发出弱拍

#### Scenario: 强切分与大音量伴奏下清晰辨识
- **WHEN** 用户在对比台播放音量高达 -5.9 LUFS 的高响度 WOTA 艺曲目并开启节拍器
- **THEN** 节拍器脉冲穿透力强、音量充足且不破音，用户清晰可辨动作与节拍重拍的卡点关系
