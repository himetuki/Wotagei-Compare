# Spec Delta

## MODIFIED Requirements

### Requirement: 独立导出工作台与 A-B 剪辑区间
系统 MUST 提供独立的导出工作台并作为顶部全局导航栏中的「导出片段」步骤直达；时间轴 A-B 剪辑区间 MUST 统一在同一根有效重叠交集轴上以单轨双滑块（左右可移动端点 A 与 B）形式进行标定，严禁拆分成两根独立的滑道；拖拽左端点手柄即时调整起点 A，拖拽右端点手柄即时调整终点 B，中间高亮填充导出覆盖区间；标题文案统一为「导出区间」，不设「全片」按键；用户在触发调整起点 A 或终点 B（包括按下 A 手柄、按下 B 手柄、在区间轨道上点击跳转、以及点击「设当前为 A」或「设当前为 B」快捷键）时，若预览处于播放状态，系统 MUST 立即将预览切换为停止状态，并将左下角播放控制按钮即刻置为「预览」（Play 图标）；在调整起止点期间，系统 MUST 将预览时间指针与画面即时切换至正在调整的对应位置（调整 A 时切至 A，调整 B 时切至 B）进行单帧画面预览；导出工作台右侧面板 MUST 进行移动端横屏视口自适应布局，子框体（起止截取、成片统计、导出进度与操作按钮）严禁超出主容器下端，底部的「开始渲染导出」按钮在任何设备上 MUST 100% 完整可见且触手可及。

#### Scenario: 截取 8 秒核心招式导出
- **WHEN** 用户在导出工作台同一根交集时间轴线上拖拽移动起点 A 端点与终点 B 端点手柄相隔 8 秒并执行导出
- **THEN** 系统沿用播放工作台的参数仅针对这 8 秒交集子区间进行逐帧离线合成，并在摘要中实时显示成片时长与总帧数，界面仅呈现一条包含左右端点的标定轴线，无独立拆分的起止滑道，无「全片」按钮

#### Scenario: 播放状态下拖动 A 或 B 手柄即刻停止并切换画面
- **WHEN** 导出工作台处于预览播放状态，用户按下并拖动起点 A 或终点 B 手柄
- **THEN** 预览播放立即切实停止，左下角控制按钮文案与图标立即变更为「预览」（Play 图标），视频画面立即切到手柄正在拖动的位置，且画面保持清晰连贯，严禁出现控制按钮残留「暂停」状态

#### Scenario: 调整 A 或 B 时预览画面实时跟随且无黑屏
- **WHEN** 用户在导出工作台拖动起点 A 手柄或终点 B 手柄，或者在区间轨道上点击任一位置
- **THEN** 预览画面即时切换至调整后的 A 或 B 对应时间点，画布呈现双通道实时合成画面，且在拖动过程中不发生画布纯黑清屏与假死

#### Scenario: 移动端横屏下右侧面板零溢出检查
- **WHEN** 用户在可用逻辑高度 360px~450px 的移动设备横屏浏览导出工作台
- **THEN** 单轨双端点标定卡片与右侧面板内所有子卡片紧凑排布无截断，且底部的「开始渲染导出」按钮完全展示在视口内，可直接点击触发离线渲染

### Requirement: 所见即所得画布逐帧离线合成与实时单帧预览
系统在导出工作台中 MUST 提供画布预览，并在预览栏内提供「预览 / 暂停」控制按钮，复用对比工作台的双视频音画硬件时间戳同步驱动引擎；系统 MUST 在导出工作台维持由动画帧（`requestAnimationFrame`）或高可靠帧调度驱动的实时渲染机制，确保寻道与播放期间视频帧解码到达后第一时间完成画布绘制；在预览播放期间，系统 MUST 依据所选声音源（CH1 原声、CH2 原声、合成节拍器或静音）实时发声并支持变速不变调；当预览播放到达 A-B 截取区间终点时，系统 MUST 自动循环重放至起点，且声音源为合成节拍器时节拍器 MUST 无缝重放并持续发声，严禁发生第二轮及后续循环失音；在预览中拖拽进度条定位或起播时，节拍器重拍 MUST 严格与统一时间轴锚点 $\tau = 0$ 保持锁相；当用户在暂停或播放状态下拖拽进度条、调整 A/B 区间或在调整后立即触发播放时，系统 MUST 具备寻道互斥与起播就绪防抖机制，严禁在视频处于寻道未就绪状态（`seeking` 或 `readyState < 2`）时进行高频重复硬赋值（Seek Thrashing）；在静态寻道过渡期间，系统画布 MUST 维持已有上一帧画面，严禁将未就绪视频帧渲染为全黑；系统 MUST 实现从属通道防雪崩锁相环追赶控制，在播放状态下点击或拖拽时间进度条 SHALL 重新定位至目标时刻并保持双侧平滑推进播放，严禁错误触发自动停止或暂停播放；离线导出时 MUST 严格复用对比工作台的几何与时间轴变换参数。

#### Scenario: 保持当前视口缩放与透明度导出
- **WHEN** 用户在播放工作台设定 0.2x 慢放后进入导出工作台并点击导出
- **THEN** 导出的 MP4 视频画面与工作台预览呈现完全一致的视野、透明度比例与 0.2x 慢放速度，无任何坐标或缩放偏离

#### Scenario: 导出台内连续播放预览
- **WHEN** 用户在导出工作台以合成节拍器为声音源点击画布下方的「预览」按钮并在播放中点击或拖动时间进度条，或画面播放推进至区间终点自动循环重放
- **THEN** 系统按当前设定倍速平滑连续呈现双视频合成画面并输出高响度节拍器声音，跳转到目标时刻后画面与声音不中断、继续平滑推进播放，循环重放后节拍器无缝继续敲击发声，按钮保持为「暂停」状态

#### Scenario: 播放状态下点击或拖动进度条保持连续播放
- **WHEN** 导出工作台处于预览播放状态，用户点击或拖动左侧面板的预览时间进度条至任一交集时刻
- **THEN** 系统原子重定位至目标时间点并保持双视频持续平滑推进播放，不触发暂停或停止，左下角播放控制按钮保持为「暂停」状态

#### Scenario: 拖动进度条后立即播放双侧流畅无卡顿
- **WHEN** 用户在导出工作台拖动预览时间进度条至任一交集时刻，并在 100ms 内快速点击「预览」开始播放
- **THEN** 系统等待双视频均完成寻道并进入可渲染就绪状态后同步启动时钟与画面渲染，双侧视频均平稳起播，不存在任一单侧画面冻结、疯狂重寻道掉帧或剧烈顿挫现象

#### Scenario: 播放中连续高频拖动进度条防雪崩
- **WHEN** 导出工作台处于预览播放状态，用户连续高频滑动时间滑块或快速点击定位
- **THEN** 系统对寻道请求进行节流保护，不向处于寻道中的视频重复推送新时刻，寻道完成后立即恢复平滑同步，双通道视频保持同频播放与音画对齐

#### Scenario: 静态寻道中间态保持旧帧不黑屏
- **WHEN** 导出工作台处于暂停状态，用户快速拖动时间轴滑块或 A/B 端点手柄
- **THEN** 寻道过渡期间画布不被强制刷成纯黑，新帧解码就绪后立即无缝刷新为目标时刻画面
