# Proposal

## Why

一线 WOTA 艺练习者在实际使用 Wotagei-Compare 进行同台慢放扣技与实机审阅时反馈了四项核心痛点：
1. **对比台缺少现场扣技高频播放器能力与色彩语义一致性**：对比台缺少 A-B 点局部循环复读与暂停态逐帧/定距步进能力，难以在不反复手动拖进度条的情况下拆解高速手腕轨迹与发力瞬态；同时顶部参数工具栏默认折叠且仅有隐蔽的小箭头拉手，用户容易忽略「更多」内置功能（如镜像、音源），且对比台与导出页的 `A` / `B` 标记需要与全站通道语义（`A` 蓝色、`B` 绿色）保持一致；
2. **向导命名黑话与步骤来回割裂（同时需避免单视频内再次割裂）**：`CH1` / `CH2` 带有非编软件代号感不够直观，同一视频的「空间标定」与「时间标定」拆在两个独立顶栏步骤里需要反复找帧切页；在现代大屏手机与桌面横屏上，空间三线与时间波形更应同屏协同标注——保留顶部 `空间●` / `时间●` 完成状态小点供随时确认进度，取消强制点击切换（也不用参考轮廓遮挡画面），并补回显式「下一步」流转按钮；
3. **高清长 GOP 视频冷启动步进黑屏卡顿**：用户初进对比台暂停态直接点击底部「步进」时，由于 `SafeVideoController.seek` 在 `readyState < 2` 时误跳过 `0s` 寻道导致冷节点未提前解码，且寻道期间 `readyState < 2` 触发了画布纯黑清屏，首次步进常需等待 2～3 秒才重新出图；
4. **实测 BPM 算法在 48kHz 与密集节奏音频下出现 ±1~2 BPM 漂移**：`[A]ddiction.mp4`（164 BPM）误测为 `163`，`金刚_真龙.mp4` 前半段《嘘の火花》（188 BPM）在 48kHz 自适应步长与单拍滞后（1T）抛物线插值下漂移为 `190`，需要从多拍梳状周期结构上彻底稳定精度。

本变更将全面升级对比台控制能力、单视频同屏合一标定体验、全流程 AB 视觉语义、冷启步进响应与多拍梳状 BPM 测定精度，使软件成为高可靠现场扣技对比工作台。

## What Changes

- **对比台 A-B 循环播放、统一蓝绿语义与导出无缝继承**：
  - 在对比工作台时间轴行新增极简 `A` / `B` 设点与一键清除控件，全站（含对比台与导出页）统一 **`A` 为蓝色（`#38bdf8`）、`B` 为绿色（`#10b981`）** 视觉语义，时间轴高亮区采用蓝到绿渐变并与两端端点竖线/滑块手柄配色保持一致；
  - 播放时钟与节拍器锁相引擎支持在该子区间内无缝循环复读；
  - 从对比台进入「导出片段」时，若对比台已启用 A-B 区间，导出页初始截取区间自动继承该 A-B 区间。
- **对比台步进微调（逐帧/拍分）、折叠倍速与「更多」抽屉文字（**BREAKING** 底栏倍速交互重排）**：
  - 将原常驻平铺的 7 档慢放倍速（`0.1x ~ 1.0x`）收敛为向上弹出的紧凑选择菜单（如 `1.0x ^`），为 `640×360` 窄横屏底栏释放充裕横向空间；
  - 在底栏新增后退/前进步进按钮（`<` / `>`）与向上弹出的步长菜单，支持动作解剖时间档（`1帧(0.033s)`、`0.05s`、`0.10s`）、节拍档（`1/4拍`、`1/2拍`）及自定义步长输入；按下步进自动暂停并按目标时间累加寻道，杜绝连续点击丢步；
  - 将对比台顶部中央原本向下的折叠拉手图标改成直观的 **「更多」** 文字按钮（展开态显示 **「收起」** 文字，替代向上箭头），提升参数工具栏可发现性。
- **单视频同屏「空间 + 时间」一体标定、非点击状态小点与取消参考轮廓（**BREAKING** 顶栏 7 步精简为 5 步）**：
  - 全应用界面可见文本统一将 `CH1` / `CH2` 改为直观的 `视频1` / `视频2`，顶部全局步骤条精简为 5 步：`导入`、`视频1`、`视频2`、`对比台`、`导出片段`；
  - 放弃参考轮廓（彻底移除 `轮廓` 开关及半透明 SVG 警报站姿轮廓图层）；
  - 在「视频1」与「视频2」单视频标定页内，**将「空间三线定线」与「底部波形/截取/锚点/BPM」放到同一界面同时标注**：视频画幅内始终可拖拽三线，底部同时呈现可拖拽定位的音频波形、`[` `]` 区间手柄与对拍控制，免除任何子模式切换动作；
  - 顶部栏保留 `空间●`、`时间●` 状态指示（拖动过三线点亮空间点，点击过「设为锚点」点亮时间点），**仅作只读状态反馈不再具备点击切换效果**，旁边保留模型下拉、`镜像` 开关与显式 `下一步 →` 按钮。
- **对比台冷节点首帧强制寻道、非阻塞零黑屏缓存与导出无缝衔接**：
  - 修复 `SafeVideoController.seek` 在 `readyState < 2` 时错误按 `|currentTime - target| < 0.005` 跳过 `0s` 寻道的逻辑，使对比台挂载双路 `<video>` 后立刻完成首次解码定格；
  - 在画布渲染循环与步进/寻道入口为两路视频各自维护最近一帧已就绪画面的离屏帧缓存（在全速播放期间零拷贝直通，仅在首帧就绪、静态暂停更新或发起寻道瞬间抓拍锁存）：当某侧视频正处于 `seeking` / `readyState < 2` 期间（且处于有效区间内）时保持渲染上一已解码画面而不清屏变黑，消除初始步进点击后等待 2~3 秒无画面的黑屏卡顿感；
  - 从 [ImportStep](../../../src/components/ImportStep.tsx) 到 [CalibrationStep](../../../src/components/CalibrationStep.tsx) 补充跨组件卸载的异步元信息/音轨补丁合入通道，确保大视频尚未解码完即点击「开始标定」时真实波形与 BPM 就绪后自动无感同步，不卡死在默认 160 BPM。
- **多拍周期梳状（Multi-Beat Harmonic Comb）高精度 BPM 测算重构**：
  - 在 [src/core/audio.ts](../../../src/core/audio.ts) 将能量包络步长提升至 ~4ms（~250 Hz，10ms 重叠 RMS 窗 + 去均值正差分起音包络），改用覆盖 `1T / 2T / 4T / 8T / 16T` 的多拍整数倍周期梳状自相关加权先验评分与分级细化搜索（`0.5 → 0.25 → 0.05 BPM`），彻底解决单拍滞后（1T）亚稳态漂移与 `44.1kHz / 48kHz / 16kHz` 网格量化导致的 1~2 BPM 误差。

## Capabilities

### New Capabilities

无（全量演进现有四大能力域）。

### Modified Capabilities

- `video-workspace`: 顶栏全局步骤从 7 步合并精简为 5 步（`导入` / `视频1` / `视频2` / `对比台` / `导出片段`）；全软件用户可见通道称谓统一由 `CH1`/`CH2` 更新为 `视频1`/`视频2`；单视频标定页内同屏同时呈现空间三线与底部波形对拍控件，顶栏保留仅作只读状态指示的 `空间●` / `时间●` 状态小点（不可点击切换）与显式「下一步」流转按钮。
- `geometric-alignment`: 保持三线正交模型与全局变量同步及镜像图标标准，空间三线标尺与波形时间定位同屏共用单个视频节点并保留老旧内核首帧呈现与降级兼容，明确不加载参考轮廓叠加层。
- `timeline-audio-sync`: BPM 检测引擎升级为 ~250 Hz 起音包络的多拍谐波梳状自相关精确测定，消除 `164→163` / `188→190` 漂移；单视频同屏标定页中拖拽/点击波形即可即时找帧并配合「设为锚点」点亮时间状态点；对比工作台打通动态 `loopInterval`、目标时间累加步进及解码预热防黑屏寻道。
- `comparison-export`: 对比工作台与导出页统一 **`A` 为蓝色（`var(--ch1)`）、`B` 为绿色（`var(--ch2)`）** 配色规范；对比台新增 A-B 循环设点与清除、继承至导出页；7 档倍速改为向上弹出菜单并新增后退/前进多粒度步进；顶部折叠拉手收起时明确显示「更多」文字。

## Impact

- **Affected Components & Code**:
  - `src/types/wizard.ts`: `WizardStep` 联合类型收敛为 5 步。
  - `src/App.tsx`: 重构 `WIZARD_STEPS`、单视频标定顶栏插槽（只读 `空间●` / `时间●` 状态指示、模型下拉、`镜像` 开关、显式 `下一步`；移除子模式状态与 `轮廓` 开关）、维护 `workbenchLoopRange` 并在导出页透传。
  - `src/components/ImportStep.tsx`: 槽位文案改为 `视频1`/`视频2`，通道数据结构增加 `spatialTouched` / `audioAnchorTouched`，补充不依赖组件挂载态的 `onPatchVideo` 异步字段合入回调。
  - `src/components/CalibrationStep.tsx`: 移除 `AlertSilhouette` 轮廓组件与 `subMode` 互斥分支，同屏渲染共享 `<video>` + 可拖三线 + 底部可拖拽定位波形/截取手柄/锚点/TAP/BPM 面板，并在异步音轨就绪后自动同步真实波形与 BPM（保留用户已编辑字段）。
  - `src/core/audio.ts`: 重构 `detectBpmFromPcm` 为 ~250Hz 零均值起音 + `[1, 2, 4, 8, 16]` 多拍梳状分级寻优算法。
  - `src/core/sync-engine.ts`: 修复 `SafeVideoController.seek` 在 `readyState < 2` 时错误跳过 `0s` 寻道的早期返回缺陷。
  - `src/components/Workbench.tsx`: 收起态梯形拉手改为显示「更多」文字；新增 A(蓝)/B(绿)循环、7 档折叠倍速、多粒度步进与每路最近有效帧离屏防黑屏缓存（寻道前锁存快照、播放态零额外拷贝）。
  - `src/components/ExportPage.tsx`: 接收 `initialLoopRange`，将 `IN (A)` 标签、「设当前为 A」按键、滑块手柄 `A` 与左端色带统一为蓝色 `var(--ch1)`（`B` 保持绿色 `var(--ch2)`）。
  - `src/index.css`: 适配只读状态徽章、同屏紧凑波形高度、蓝绿 A/B 样式、`640×360` 与 Chrome 74 兼容边距（不使用 Flexbox `gap`）。
- **Architecture Decisions**:
  - `docs/decisions/AgDR-0034`、`AgDR-0035`、`AgDR-0036`、`AgDR-0037`（标注 `AgDR-0036` 已被废弃、`AgDR-0034` 子模式分屏条款被 `AgDR-0037` 更新，新增 `AgDR-0037` 记录同屏合一、「更多」文案、多拍梳状 BPM 与步进防黑屏预热决策）。
